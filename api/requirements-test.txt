# ============================================================================
# 测试/开发用依赖 —— 从 requirements.txt 派生，**剔除测试不需要的重依赖**
# ============================================================================
#
# 为什么存在这个文件：
#   requirements.txt 里含 `sentence-transformers`（拖 **torch**，GB 级）。本机只有 8GB 内存，
#   `docker build` 装完整 requirements.txt 会打穿内存而挂死（已实测）。
#   但本仓**不需要** torch —— `api/reranker.py:14` 把 `sentence_transformers` 放在
#   `get_reranker()` **函数内**真懒加载；`api/document_preprocessor.py:171` 那处还带 try/except 兜底。
#   ⇒ 只要不调用 `rerank()`，整套服务与测试都能跑。
#
# 用法（本仓根目录，venv 已在 .gitignore 里）：
#   python3.10 -m venv venv
#   venv/bin/pip install -r api/requirements-test.txt
#
# 与 requirements.txt 的差异 —— **两类改动，都是实测逼出来的**：
#
# 【第一类 · 做减法】剔除测试不需要的重依赖
#   剔除 sentence-transformers  ← 拖 torch，本仓懒加载不需要
#   剔除 transformers           ← 同上（是 sentence-transformers 的依赖）
#   剔除 camelot-py[cv]         ← 不在导入链（api/ 下顶层 0 命中）；拖 opencv
#   剔除 opencv-python          ← 不在导入链
#   剔除 ragas                  ← 只被 archive/scripts/ 用，而 archive/ 不入库
#   剔除 datasets               ← 同上
#   剔除 locust                 ← 不在导入链；实机压测须显式决定（每次请求真花钱）
#                                  需要时：venv/bin/pip install 'locust>=2.30.0'
#
# 【第二类 · 补约束 + 换包名】⚠️ 这两条同时是 requirements.txt 的**真实缺陷**，不是本文件独有
#   ① 给 langchain 系列**加上界**。requirements.txt 写的是 `langchain>=0.3.13`（无上界），
#      pip 会装到 **langchain 1.x** —— 而代码是按 0.3.x 写的。实测后果：
#        api/api_v1_rag.py:681  `from langchain.agents import create_tool_calling_agent, AgentExecutor`
#        → ImportError: cannot import name 'create_tool_calling_agent' from 'langchain.agents'
#      ⇒ **今天重跑 `docker build` 装到的就是 1.x，应用会在 import 阶段崩**。
#      这解释了为什么那张 2026-07-01 的镜像不能随便重建。
#   ② `duckduckgo-search` 已改名为 `ddgs`。requirements.txt 还钉着旧名，
#      而 api/agent_graph.py:43 在**模块级**调 `DuckDuckGoSearchRun()` ⇒ 缺 ddgs 则 import main 必崩。
#
# 【已实测通过的组合】（本文件装出来的版本）
#   fastapi 0.141.1 + starlette 1.6.0 · pydantic 2.13.5 · langchain 0.3.x · langgraph 1.x
#   numpy 1.26.4（满足 numpy<2）· 无 torch/transformers/sentence-transformers
#
# ⚠️ 剔除 `sentence-transformers` 的**代价**（已登记进 docs/重构计划-2026-09-15.md 的清单③-a）：
#    `/rag/search?mode=accurate`、`?mode=full`、`hybrid_search.py` 的 `rerank_search()`
#    **在本环境跑不了**。默认 mode 是 `accurate_norerank`，**默认路径不碰 torch**。
# ============================================================================
