总览

无需登录也能看

使用前必读

怎么验证它真的做完了

主要功能

  • 对话 登录 → 提问 → 逐字流式回答 → 点开引用看原文 → 随时停止。
  • 检索三模式未上线 向量 / 混合（BM25+RRF）/ 精排，外加查询改写。施工中（刀 3）。
  • 人工接管 敏感工具调用会停下来等人批；点开看完整上下文，批准 / 拒绝 / 代填结论。
  • 成本可见未上线 每次调用的 token 与费用、按会话与用途汇总、四层额度。施工中（刀 4）。
  • 执行轨迹 一次调用里 agent 走了哪些步、每步花了多少（两轴分屏）。

其他功能

  • 知识库未上线 上传 / 删除文档，自己传一篇就能立刻在对话里问它。施工中（刀 10）。
  • 工具 / MCP未上线 可用工具清单、健康状态、MCP 动态工具表。施工中（刀 5）。
  • 记忆未上线 写入 / 检索长期记忆。施工中（刀 5）。
  • 执行器未上线 在无网硬化容器里跑代码。施工中（刀 6）。
  • 预算 / 熔断未上线 额度检查、预估、拦截记录。施工中（刀 4）。
  • 系统状态未上线 health / ready / Prometheus 指标。施工中（刀 6）。
  • 评测 接入 Agent 生产就绪评测门（现状是占位页）。
  • 运维探针未上线 限流桶 / 配额 / 缓存的可见证据（调试视角）。施工中（刀 7）。
