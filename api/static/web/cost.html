这一页上的三种数（⛔ 别混着读）

读库 —— 数在 PostgreSQL 里，重启不影响，是你的全时累计。

进程内存 —— 数在服务进程的内存里，平台重启容器就归零（这是平台限制，⛔ 不是故障）。 它和上面那几格不一样是正常的。

配置常量 —— 代码里写死的估价表，与运行、与是谁都无关。

⚠️ 演示机上这几格大概率都是「清零态」（容器刚重启）—— 那不是"系统坏了"，是平台会重启容器。
