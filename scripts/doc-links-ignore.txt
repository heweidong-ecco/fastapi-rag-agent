# doc-links-ignore.txt —— `check_doc_links.sh` 的豁免清单
#
# ## 两种写法
#
#   普通正则         匹配【候选路径】      例：`^eval/`
#   `@file:正则`     匹配【来源文件】      例：`@file:^CHANGELOG\.md$` ⇒ 整份不检查
#
# `#` 开头是注释，空行忽略。⚫ 命中的不计入 🔴 真断链。
#
# ## ⛔ 加一条之前先想清楚：**它为什么不算缺陷？**
#
# 这份清单是**给人审阅的**。**"懒得修"不是理由**；"它本来就不属于本仓"
# 或"本仓规矩就是不改写原始记录"才是。
# 📌 出处：`docs/复盘/2026-09-29-结果为空就断言能力不存在.md` 规则 1
#    （「全称否定 / 豁免 ⇒ 必须附一条能打印出来的理由」）。
