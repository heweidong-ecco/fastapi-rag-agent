# demo · 演示版

> ⚠️ **先说清**：本目录讲的是 **demo（演示版）**，
> ⛔ **不是**本仓（完整版）的说明 —— 完整版看仓库根的 `README.md`。
> 两者的**内容与产出不一样**（见下面「与『本仓』的边界」）。

## 它是什么

把这个服务**变成一个能分享的链接**，让别人**点得到、看得见** ——
跑在**魔搭社区的创空间**上（**单容器**）。

⭐ **判据**（业务方原话，**他说这是第 3 次说**）：

> 「**95% 的人不会去看代码**……只会看你**做了哪些功能、哪些接口** ——
> 这些接口他们**自会用眼睛看到和点击**，**显示了，才知道你有做**。
> ……**别人无法点击使用，95% 的人会直接当你没做**。」

⇒ **「藏进后端」= 等于没做**；**「只有一页、其余靠读代码才发现」= 等于没做**。
