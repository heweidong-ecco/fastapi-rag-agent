## 0. 完整过程图解（**先读这一节**）

### 0.1 全书的核心：四个环节，断一个就打不开

```
【域名】demo.abc.com        ← 给人看的、好记的名字
      ↓ DNS 解析（把名字翻译成 IP）
【公网 IP】47.98.12.34      ← 机器在互联网上的真实门牌号
      ↓
【安全组】允许 8000 吗？     ← 门口保安。默认只开 22（SSH）
      ↓
【云主机】api:8000          ← 你的服务
```

> **四个环节，断任何一个都打不开。**
> 这就是那个常见困惑的答案：**"我机器也买了，怎么还是打不开？"** —— 因为后面几环还没接上。

### 0.2 为什么 `127.0.0.1` 别人打不开

> `127.0.0.1` 的意思是 **「我自己」**。**任何一台电脑上**，`127.0.0.1` 都指它自己。
>
> - 你打开 `127.0.0.1:8000` → **你电脑**上的 8000 → 有东西 ✅
> - 其他人打开 `127.0.0.1:8000` → **他自己电脑**上的 8000 → **空的** ❌
>
> ⇒ 必须换成一个**"全世界都指向你那台机器"**的地址 —— 这就是**公网 IP** 和**域名**的作用。

### 0.3 三个最容易混的概念

**① 域名 ≠ HTTPS**

| | 是什么 | 类比 |
|---|---|---|
| **域名** | 一个**名字**（`demo.abc.com`） | **门牌号** |
| **HTTPS** | **加密**（内容别人偷看不到） | **门上的防盗锁** |

- 可以**有域名但没 HTTPS**（走 HTTP 明文）· 也可以**没域名但有 HTTPS**（用 IP 申请证书，但基本没人给你签）
- **真正的关系**：`想要 HTTPS ⇒ 需要证书 ⇒ 签证书的机构要求你有域名`
  ⇒ **域名是 HTTPS 的【前提】，不是 HTTPS 本身**

**② HTTPS 不是"在域名控制台点一下就有"**

- **域名控制台只管 DNS 解析**，不管加密。
- 要走阿里云自建 HTTPS，你得：**申请证书 → 下载 → 装到服务器上**（配 Nginx 的 `ssl_certificate`）—— **是要动服务器配置的。**
- ⚠️ **阿里云免费证书有效期只有 3 个月**（2023-11 起从 12 个月缩短），**不可续费** ⇒ 到期要**重新申请 + 重新部署**。要 1 年得花 **68 元/年**。
- ⚠️ 免费证书**不支持通配符 `*.abc.com`** ⇒ "一个域名挂多个子域名"要**付费证书或多张证书**。

**③ 域名可以对应多个后端** ✅

```
子域名法（最简单）                     路径法
rag.abc.com   → 服务 A                abc.com/api1 → 服务 A
agent.abc.com → 服务 B                abc.com/api2 → 服务 B
（各一条 DNS 记录）                    （需要一层反向代理）
```

- 你现在**只有一个后端**，用不上 —— 但架构上**随时可加**。
- 📌 **这是展示时的隐藏加分项**：将来第二、三个 demo 做出来，**一个域名 + 不同子域名**就能挂上去 —— **一个域名展示多个作品**。

### 0.4 ⚠️ 路线选择：**这一步决定后面所有事**（2026-09-24 查证）

> 🔴 **大陆节点 + 域名 + 80/443 提供 web 服务 = 必须 ICP 备案。**
> 未备案时阿里云监测系统会**阻断**，80/443 被强制拦截，返回"未备案禁止访问"；**备案审核期间不允许提前上线**。
> 非中国内地地域（香港/海外）**不需要备案**。
> 阿里云官方文档里，安装证书的**前提条件**就写着：「域名已解析到阿里云服务器（**国内地域需完成 ICP 备案**）」。

| 路线 | 备案 | HTTPS | 成本（1 个月窗口） | 评价 |
|---|---|---|---|---|
| **A. 大陆节点 + 域名 + 自装证书** | 🔴 **必须，数周** | 自己装，**3 个月过期** | 域名 + 服务器 | 🔴 **会把你的时间窗口吃掉** |
| **B. 香港节点 + 域名 + 自装证书** | ✅ 不用 | 自己装，3 个月过期 | 域名 + **香港服务器（更贵）** | 🟡 可行，但要自己维护证书 |
| **C. 域名 + Cloudflare 隧道** | ✅ 不用 | ✅ **自动，永不过期** | 域名 + 服务器 | ✅ **一次解决两个问题** |
| **D. 不用域名，直接用 IP** | ✅ 不用 | ❌ **没有** | 只要服务器 | ✅ **最省，但没 HTTPS** |

> 💡 **判断依据**：
> - **要省事 + 要 HTTPS** → **路线 C**（Cloudflare 自动证书，不用管 3 个月过期，还送免费口令）
> - **要最省 + 能接受没 HTTPS** → **路线 D**（备案备的是域名，**IP 直连不需要备案**）
> - **一定要阿里云自建 HTTPS + 不要 Cloudflare** → **必须走 B（香港节点）**，因为走 A 会撞备案

> 📌 **备选**：如果坚持要走 A（大陆 + 域名），**备案要提前几周启动**，且要主体资质。**在"只用一个月"的前提下，我不建议。**

## 5. 阶段 ⑤⑥⑦：买域名 → 搬上云 → 开通路

### 5.1 买域名（**只在走路线 B / C 时需要**）

> 🔴 **买之前先回看 §0.4 定路线。** 路线 D（IP 直连）**不需要域名**。

#### 💡 关键结论：**域名不一定要在 Cloudflare 买**

**只要域名的 DNS（NS）托管到 Cloudflare，Tunnel 就能用** —— 注册商是谁无所谓。
⇒ **在哪买，只影响「价格 + 付款方式」。**

| | **阿里云**（国内注册商） | **Cloudflare Registrar** |
|---|---|---|
| 付款 | ✅ **支付宝 / 微信** | 🔴 **只收信用卡 / 借记卡 / PayPal**（Visa·Master·Amex·Discover）<br>**不支持支付宝微信** —— 国内需**双币卡或虚拟卡** |
| 价格 | 首年常有大促销（几元–十几元）；**续费偏贵** | **成本价，零加价**：`.com` ≈ **$10.44/年**（≈75 元）· `.org` ≈ $7.52 · `.co` ≈ $8.00 · `.net` ≈ $11.86 · `.io` ≈ $32.5+ |
| `.cn` | ✅ 支持 | 🔴 **不接受** .cn 等中国大陆 TLD |
| 新注册 | ✅ | ✅ 支持（2018 年上线时只能转入，后来才支持新注册） |

> 💡 **你只用一段时间 ⇒ 看「首年价」，不看续费价。**
> **最便宜的路 = 阿里云买首年促销的国际后缀 → NS 改到 Cloudflare。** 支付宝付款，几元–十几元搞定。

#### ✅ 推荐做法（路线 C）

1. **在阿里云买一个国际后缀域名**（`.com` 最稳妥）
2. **改 NS 指向 Cloudflare**：阿里云控制台 → 域名管理 → **修改 DNS 服务器** → 填 Cloudflare 给的两个 NS
   - ✅ **不需要转移注册商**，域名注册信息仍留在阿里云
   - 建议先在 Cloudflare 添加站点、**导入原有解析记录**，两边一致再切（零停机）
3. 之后在 Cloudflare 里配隧道 + Public Hostname

#### ⚠️ 三个坑

| 坑 | 说明 |
|---|---|
| 🔴 **别买 `.cn`** | Cloudflare **不接受** .cn 等中国大陆 TLD；且 .cn 能否托管到 CF 未明确。<br>⇒ **买 `.com` / `.org` 等国际后缀** |
| ⚠️ **买之前查 Cloudflare 的 TLD 支持列表** | 极便宜的促销后缀（如某些 `.top` / `.xyz`）**Cloudflare 不一定接**。<br>**省钱的前提是"CF 认这个后缀"** |
| ⚠️ **Cloudflare 不支持单独托管子域名** | 只能整个域名托管。你要挂多个 demo，用**子域名**（`rag.abc.com`），**不是**托管两个不同的域名根 |

> 📌 补充：**备案和 DNS 解析是两码事**（备案备的是域名 + 服务器，DNS 交给谁都行）。
> 但走**路线 C** 本来就**不需要备案**（不暴露 80/443）—— 所以这里不冲突。
>
> ⚠️ **走路线 B（香港节点自建 HTTPS）时**：阿里云免费证书**只有 3 个月且不可续费**，要自己装到服务器上。
> ⚠️ **不要走路线 A**（大陆 + 域名自建证书）—— 撞 ICP 备案，见 §0.4。

### 5.2 把代码搬上云（**4 个动作**）

```
① 云主机上装 docker
② 把代码传上去        git clone，或 scp -r 整个文件夹
③ 把 .env 传上去      ⚠️ 别用公开渠道传，别提交进 git
④ docker compose build && docker compose up -d
```

> **你的代码一个字不用改 —— 换的只是"运行它的机器"。**
>
> ⚠️ **④ 里的 `build` 不能省** —— 云上同样会踩 §2.3 那个 `python-multipart` 的坑，
> 因为那也是"镜像是旧的"。**`build` 就是修法。**
>
> ⚠️ 如果 `github.com` 连不上（定向拦截），用 SSH 地址：`git clone git@github.com:heweidong-ecco/fastapi-rag-agent.git`
>
> ⚠️ **做完这一步，外部仍然打不开** —— 服务在跑了，但"路"还没通。

### 5.3 开通路（**二选一 · 这一步才第一次"能打开"**）

**走法 A：直接开端口**（= §0.4 的路线 D / B）
```
其他人 → http://47.98.12.34:8000 → 云主机 8000 → api
```
- 做：**安全组放行 8000**
- ❌ 没有 HTTPS（明文）· ✅ 不需要域名、不需要备案

**走法 B：Cloudflare 隧道**（= §0.4 的路线 C）← **推荐**
```
其他人 → https://demo.abc.com
              ↓
        Cloudflare 边缘（HTTPS 在这里终止，证书自动）
              ↑ 隧道（cloudflared 主动连出去，不是等外面进来）
        云主机上的 cloudflared → api:8000
```
- 做：Dashboard 建隧道拿 token → 加一个 `cloudflared` 容器 → 配 Public Hostname
- ✅ **云主机完全不用开任何入站端口**（安全组可以全关，公网 IP 不暴露）
- ✅ **HTTPS 自动**，证书不用管（**不会 3 个月过期**）
- ✅ **Cloudflare Access 免费口令** —— 正好解决"不想对全世界开放"
- ⚠️ **必须用「命名隧道」，不能用「快速隧道」** ——
  **快速隧道会缓冲 SSE，直接废掉你的硬门 A（流式输出）**，而且地址每次重启就变

```yaml
# 在云主机的 docker-compose.yml 里加这个服务
  cloudflared:
    image: cloudflare/cloudflared:latest
    container_name: rag-tunnel
    restart: unless-stopped
    network_mode: "service:api"        # 与 api 共用网络栈
    command: tunnel --no-autoupdate run --token ${TUNNEL_TOKEN}
```
> `network_mode: "service:api"` 的好处：Dashboard 里 URL 直接填 `http://localhost:8000`，不用琢磨容器名。
> ⚠️ **token 是敏感凭据**（拿到它的人都能开隧道）—— 跟 `.env` 同级对待，**绝不入库**。
