### 2.1 根因（已定位到具体行）

```
RuntimeError: Form data requires "python-multipart" to be installed.
```
崩溃点在 `api_v1.py:369` 的 `upload_document`（用了 `Form` / `File`）。

**但 `requirements.txt:73` 里明明有** `python-multipart>=0.0.9` —— 所以**不是代码问题**。

真正的原因：

| 事实 | 值 |
|---|---|
| `rag-api` 实跑镜像 | 🔴 `my-fixed-name-api:latest`（**2026-07-02** 构建，2 个月前） |
| compose 期望的镜像 | 🔴 `fastapi-rag-agent:latest` —— **从未 build 过**（`docker image inspect` 确认不存在） |

> ⇒ **旧镜像构建于 `python-multipart` 进 requirements 之前。**
> **修法不需要改一行代码 —— 只要重建镜像。**
>
> ⭐ **记住这一点**：**上云时会一模一样踩到**（云上也要 build）。**云上第 ④ 步的 `build` 不能省。**

### 5.2 五步

| # | 步骤 | 对准公网后的变化 |
|---|---|---|
| 1 | 起被测、核 `/health` | 改成核 `curl <公网URL>/health` |
| 2 | 拿被测 API Key（`api_keys` 表里 `sk-` 开头的；**网页登录口令不是 API Key**） | **给 eval 单独发一把 key**（理由见 5.3） |
| 3 | **seed 知识库（必做）** | ⚠️ **线上知识库是另一份，必须重新 seed** |
| 4 | 填 `.env`：`EVAL_SUT_FASTAPI_BASE_URL` / `_API_KEY` + `EVAL_JUDGE_*` | base_url 填**公网地址** |
| 5 | `python -m eval_gate run --evals eval/fastapi_rag_golden.evals.json` | 出 **exit code** + 报告 + trace |

### 5.3 对准公网后新增的三个注意点

1. **🔴 配额打架** —— eval 跑全量**会消耗被测额度**。如果给线上设了每日成本上限，
   **跑分可能触发 `E_SUT_QUOTA` → 整批 aborted → exit 3**。
   ⇒ **给 eval 单独 key + 预留额度**，别让"上线保护"把"跑分"锁死。
2. **⭐ 快照兜底** —— `.env` 里的 `EVAL_SUT_FASTAPI_SNAPSHOT` 可**改走快照回放**（契约里的三种取法之一）。
   ⇒ **被测挂了也能演示。提前录一份备用。**
3. **TLS 坑会变** —— `docs/部署.md` §6-2 那个 `localhost` → IPv6 的坑在公网下消失；
   但**公网证书链**可能出现新坑（§6-1 的 `SSL_CERT_FILE` 经验要保留）。

### 5.4 为什么这条线性价比最高

它把 **exit code `0/1/2/3`** 变成**对着线上系统的真实判分**。
且 **`agent-eval-gate` 不需要部署**（纯 CLI、零运行时依赖、**无服务端**）⇒ **不增加服务器成本，也不增加运维面。**
⛔ **别给它造网页** —— 它的说服力在退出码上。

### 要求摘要（详情与验收标准见 §8.1）

| 编号 | 要求 |
|---|---|
| **R1** | **四层限额**（单次 token / 单会话累计 / 单用户频率 / **全局日级**）**每层都生效** |
| **R1.3** | 🔴 限额**必须对匿名 / 未登录请求也生效** |

## 7. 这个仓已知的坑（原仓文档记录，都会在部署时复现）

| # | 症状 | 根因 | 处置 |
|---|---|---|---|
| 1 | judge 全挂 `CERTIFICATE_VERIFY_FAILED` | 本机有 TLS 拦截，其 CA 只在系统信任库 | 设 `SSL_CERT_FILE=/etc/ssl/cert.pem` |
| 2 | 前几条成功后 `Connection reset by peer` | `localhost` 解析到 **IPv6**（`::1`），被别的进程占着 | base_url 用 **`127.0.0.1`** 而非 `localhost` |
| 3 | 模型名报不存在 / 行为变化 | 模型名被官方停用 | 换现行名；⚠️ **网关可能不校验模型名，返回 200 不代表名字有效** |
