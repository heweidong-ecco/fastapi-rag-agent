## 二 · 接口速查（**从代码抠的** · 2026-10-09）

> 鉴权：全部走 **`X-API-Key`** 头（⛔ 不是 `Authorization` —— 见 `demo/` 那条平台约束）。
> ⚠️ 前端**写死的 URL 必须带 `/api/v1`** —— `api/test_web_pages.py` 会扫。

| 方法 | 路径 | 参数 | 响应键（字面量） | 谁在用 |
|---|---|---|---|---|
| `GET` | `/agent/pending` | — | `items` · `count` · `requested_by` | `approvals` |
| `GET` | `/agent/pending/context` | `thread_id` · `owner?` | `messages` · `owner` · `graph` · `rounds` · `next` · `status` · `message` | `approvals` |
| `GET` | `/agent/approvals/history` | `limit=50` · `offset=0` | `events` · `count` · **`has_more`** · `limit` · `offset` | `approvals` |
| `POST` | `/agent/approve` | `thread_id` · `approved` · `edited_answer?` · `owner?` | `answer` · `status` · `rounds` · `pending_tool_calls` · `forced_finish` · `message` | `approvals` |
| `GET` | `/agent/trace/{thread_id}` | — | `trace` · `error` | `trace` |
| `GET` | `/agent/trace/{thread_id}/cost` | — | `items` · `total` · **`truncated`** · `thread_id` | `trace` |
| `POST` | `/rag/stream_search` | `req.question` · `thread_id` | **SSE**（⛔ 非 JSON） | `chat` |

### 2.1 两个列表的**分页形状**（⛔ 不一样，别混）

| 端点 | 做法 | 形状 |
|---|---|---|
| `/agent/approvals/history` | **A · `offset` 翻页** | 回 `limit` / `offset` / **`has_more`** ⇒ 页面画「上一页 / 下一页」 |
| `/agent/trace/{id}/cost` | **B · 截断 + 说出来** | 回 **`truncated`** + **服务端算的 `total`** ⇒ 页面显示 `total`、⛔ **不自己求和** |

⇒ 🔴 **两者共同的底线是「必须说出来」**，而且它**已经是门**：
`venv/bin/python -m pytest api/test_truncation_declared.py -q`（交了 `limit` 就必须回 `truncated` 或 `has_more`）。

### 2.2 `chat` 那条是 **SSE** —— 帧类型（前端在认这几种）

`done`（`[DONE]` 哨兵）· `error` · `usage` · `sources` · `no_answer` · 其余按内容帧处理。
⚠️ 解析在 **`api/static/js/sse.js`**（**全站唯一**解析引用的地方）⇒ ⛔ 别在页面里另写一份正则。

### 2.3 两个"列表项"的字段

* `/agent/pending` 的 `items[]`：`thread_id`（**拼过的键**）· `raw_thread_id` · `user_name` · `graph` · `tool_calls[]` · `rounds` · `since`（unix 秒）
* `/agent/approvals/history` 的 `events[]`：`owner` · `actor` · `decision` · `edited` · `rounds` · `reason`

## 三 · 逐页编排（5 页 · 每页四件：**目的 / 内容 / 接口 / 状态**）

### 3.1 `GET /chat` → `web/chat.html`（**首页 · 最重要**）

| | |
|---|---|
| **目的** | 访客**一眼看懂这是干什么的** + **当场能问** |
| **内容** | ① sidebar：品牌块 · 导航 · **会话列表** · 新会话 ② page-head：标题 + 一句说明 ③ 消息流 ④ 底部输入区 |
| **接口** | `POST /api/v1/rag/stream_search`（SSE） |
| **首次（未登录）** | **渐变 hero + 登录卡** —— 这是访客看到的**第一屏**，⛔ 不能只是几行裸元素 |
| **首次（已登录 · 无会话）** | 消息区**空态**：说清"问点什么" + **给 2–3 个示例问句**（⛔ 不是空白） |
| **流式中** | 逐字追加 + **停止**按钮可见 |
| **拒答** | 灰条「资料里没有」（⛔ 不是警示黄 —— **拒答不是故障**） |
| **熔断** | 琥珀卡「今天的额度用完了」（文案**裁过**，⛔ 别改） |
| **引用** | 每条回答下面挂**可点开的卡**（就地展开/收起） |

### 3.2 `GET /approvals` → `web/approvals.html`

| | |
|---|---|
| **目的** | 演示**人工接管** —— 硬门 D 那条"界面上找得到" |
| **内容** | ① 待接管队列（表格）② 点一行 ⇒ **完整上下文** ③ 裁决区（批准 / 拒绝 / 代填）④ 裁决历史（**带分页**） |
| **接口** | `GET /agent/pending` · `GET /agent/pending/context` · `POST /agent/approve` · `GET /agent/approvals/history` |
| **首次** | 顶部一个 **API Key 输入**（没有它就什么都看不到）—— ⚠️ **这一屏要能看出"这是什么页"** |
| **空（队列空）** | 「现在没有等待审批的会话」+ **为什么会有这一栏**的一句 |
| **加载** | 队列与历史各自独立 —— ⛔ 一个转圈不该把另一块也遮住 |
| **错** | 🔴 **页面级的过滤才是那道边界** —— 接口的四类拒绝**全是 HTTP 200 + `{"status":"error"}`** ⇒ ⛔ **只看 `r.ok` 会把"无权查看"当成成功** |
| **分页** | 历史：`has_more` 决定「下一页」可不可点；**只有一页 ⇒ 整个控件不显示** |

### 3.3 `GET /trace` → `web/trace.html`

| | |
|---|---|
| **目的** | 演示**执行轨迹 + 花费**，且**诚实**（"为什么空"要写出来） |
| **内容** | ① page-head（标题 + API Key + thread_id + 查询）② **两轴并排**：左追踪轴（`耗时` / `工具调用` 两张 KPI 卡 + 步骤表）· 右成本轴（逐笔表 + 合计） |
| **接口** | `GET /agent/trace/{id}` · `GET /agent/trace/{id}/cost` |
| **首次（无 thread_id）** | ⛔ **不要空表** —— 说清"先填 thread_id" |
| **空（追踪轴）** | ⭐ **必须解释"为什么空"**：对话页走的是检索链，**那条链本来就不写轨迹**（`DEC-093`）—— 这不是坏 |
| **截断（成本轴）** | 显示**服务端给的 `total`**（⛔ 不自己求和）+ 一行「**只显示最近 N 笔**」（`truncated`） |
| **两轴关系** | 🔴 **⛔ 不合并成一棵树** —— 没有共同的步 id（并排正是这个意思的视觉表达） |

## 四 · 状态矩阵（**每页都要有，⛔ 不许只做默认态**）

| 状态 | 什么时候 | 显示什么的**底线** |
|---|---|---|
| **首次** | 页面第一次打开 | 说清**这是什么**；未登录 ⇒ 登录面；已登录无数据 ⇒ **空态带"为什么空"** |
| **加载中** | 请求发出、还没回 | ⛔ **不许只把旧内容变灰** —— 要有可见的进行态（`.btn[aria-busy]` 那套已有） |
| **空** | 请求成功但没数据 | ⭐ **必须解释为什么空**（规则见 `frontend/README.md` §四 第 8 条） |
| **错** | 请求失败 / 业务拒绝 | 用 `--bad` / `--warn` 的语义色，⛔ **不用好看的渐变表示"出错了"** |
| **截断** | 有 `has_more` 或 `truncated` | 🔴 **必须说出来**，⛔ 不许静默截（**已有门**：`test_truncation_declared.py`） |
