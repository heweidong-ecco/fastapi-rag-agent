# 决策记录：DEC-030 · 降级分支不许吃掉真实失败原因

- 日期：2026-09-21
- 状态：**已采纳并执行**
- 关联：`docs/复盘/2026-09-21-拿动作成功当结果正确.md` **§五·A** · `ROADMAP.md` 剩余待办

## 决策事项

`api/plan_execute.py:298-301` 的「失效工具降级」分支，用 **裸 `except: pass` + 预设兜底文案**
把真实失败原因吃掉了。**怎么办？**

## 🔴 发现（复盘 §五·A 的原始记录）

```python
fallback_result = f"工具 {tool_name} 当前不可用，使用备用策略生成结果。"   # ← 先填一个【编好的】串
try:
    fallback_result = execute_single_step(step, step.get("input", ""), context)
except:            # ← 裸 except
    pass           # ← 失败原因【被丢掉】
```

**四处问题**（严重度递减）：

1. ⚠️ **callee 定的契约，它自己点名的 caller 违反了** ——
   `execute_single_step` 的 docstring（`:562`）明文写
   「**失败一律【抛异常】，不吞成错误字符串** —— 上游两条路都是靠异常工作的」，
   **并且点名了就是这个降级分支**。
2. 🔴 **失败原因被 `pass` 丢掉** —— 没日志、没 trace，事后无法区分"哪一步、为什么降级"。
3. 🔴 **裸 `except:`** —— 连 `KeyboardInterrupt` / `SystemExit` 也吞。
4. ⚠️ **产物无法与真结果区分** —— 编好的串进 `results` 与 `context`，下游当它是真内容；
   文案「**使用备用策略生成结果**」**读起来像有意降级**，实际是吞了一个异常。

**⇒ 与那份复盘的根因同一条**：「**动作结果**」与「**真实结果**」被压成了同一个东西。

## 备选方案

| 方案 | 一句话 | 本次 |
|---|---|---|
| **甲 · 保留原因**（**采纳**） | 去掉裸 `except`，**真实失败原因写进结果** | ✅ |
| 乙 · 先挂着 | 只登记，不动代码 | ⬜ 未采纳 |
| 丙 · 让降级分支**直接抛异常** | 完全按 docstring 的字面来（不让它吞） | ⬜ 未采纳 |

**业务方 2026-09-21 裁：「修 —— 去掉裸 except，保留失败原因」**（= 甲）。

## 决策与理由

**甲。** 三条理由：

1. **它先是一个"看不见"的问题** —— 改前输出是 **N 行一模一样的套话**，
   连"**哪一步**、**为什么**"都读不出来（实测：5 行全写「步骤1」，5 行文本完全相同）。
   ⇒ **先让它可见**，才有后面可谈的。
2. **降级本身是【有意设计】，不该删** —— 这个分支的意义就是"工具死了也别整条计划崩"。
   所以问题**不在"它吞了"**，在**"它把原因也一起吞了"**。
3. **丙 不采纳的理由**：让降级分支直接抛，会把端点的失败形态从
   「**返回一段带原因的文本**」变成「**抛出去**」—— 那是**比本次更大的行为改动**，
   而且与"降级分支存在的目的"相悖。**它属独立决策，本次不做。**

⚠️ **与 docstring 的关系（核对过，不冲突）**：`:562` 那句约束的是
**`execute_single_step` 自己不许吞**（它确实没吞 —— 有 `test_unknown_tool_raises_instead_of_returning_a_string`
与 `test_tool_exception_propagates` 守着）。**降级分支接收这个异常、并把它【如实写进结果】，是契约的下游用法，不是违反。**

## 执行内容

`api/plan_execute.py` 的降级分支：

```python
try:
    fallback_result = execute_single_step(step, step.get("input", ""), context)
except Exception as e:                                   # ← 不再是裸 except
    fallback_result = (
        f"工具 {tool_name} 已连续失败 3 次，本次降级**未执行**；"
        f"真实原因：{type(e).__name__}: {e}"              # ← 原因留下了
    )
```

新增 2 条用例（`api/test_plan_execute_tools.py`）：

| 用例 | 守什么 |
