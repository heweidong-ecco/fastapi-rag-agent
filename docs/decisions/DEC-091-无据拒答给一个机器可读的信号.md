## 一 · 这条要解决什么

硬门 B 的判定是**两半**：

> 「先问库里 covered 的 → 点开看原文片段；**再问一个库里没有的 → 明确拒答（说"资料中没有"，而不是编）**」

前半由 `DEC-085` / `DEC-089` 做完（引用卡片 · 就地展开 · chunk id + 相似度分）。**这份管后半。**

⚠️ 但"后半"到底缺什么，**开工前是不知道的** —— 所以业务方 2026-10-06 裁「**先测现状（spike）**」。
下面 §二 就是那次测量的结果，**它推翻了开工前那个想当然的方案**。

## 二 · 🔴 先测了：真栈 spike 三轮（这是本份 DEC 最该留住的部分）

**环境**：真 PG（`postgres-rag`，admin 名下 112 篇）+ 真 embedding（`text-embedding-v2`）+ 真 LLM
（`deepseek-v4-flash`）。**在进程内直接调 `rag.stream_search()`**，⛔ 不走 HTTP、⛔ 不碰 API key。
探针用完即删（`/tmp/spike_wuju{,2,3}.py`）。

### 第 1 轮 —— 三问，看着"干净得可疑"

| 问 | 库里 | 检索最高相似度 | 结果 |
|---|---|---|---|
| Redis 和 Docker 怎么配合部署？ | ✅ 有 | 0.80 | **答**（214 字，带 `[来源:1]`） |
| 法国大革命爆发于哪一年？ | ⛔ 无 | 0.088 | **拒**（「根据现有资料，无法回答。」） |
| 请写一首关于秋天的五言绝句。 | ⛔ 无 | 0.088 | **拒** |

⇒ 一眼看去：「能答 ≥ 0.61 / 该拒 ≤ 0.09」，**加个相似度下限就完事了**。

### 🔴 第 2 轮 —— 换成**话题相邻**的硬例，那条"干净断层"就没了

第 1 轮的题**太容易**：问的是完全不相干的题材，检索相似度天然塌到 0.09。
真正危险的是**同一篇文档的邻居问题** —— 上下文看着很像，但**那个具体事实不在库里**：

| 问 | 库里 | 检索最高相似度 | 结果 |
|---|---|---|---|
| 公司 2025 年第四季度 **净利润**是多少？ | ⛔ 无（库里有的是**营收**） | **0.766** | 拒 |
| FastAPI 的**依赖注入**怎么实现？ | ⛔ 无（库里有 FastAPI 一句话简介） | 0.640 | 拒 |
| 苹果公司 2024 年的**研发投入**是多少？ | ⛔ 无（库里有苹果公司简介） | 0.522 | 拒 |
| 紫色长颈鹿在月球上跳芭蕾舞是什么？ | ✅ 有（**逐字**原文） | **0.794** | 答 |

**⇒ 能答的最低 0.794，该拒的最高 0.766 —— 差 0.028。**

### 第 3 轮 —— 同一个问题跑 3 遍，量拒答率与措辞稳定性

「公司 2025 年第四季度的净利润是多少？」× 3 ⇒ **3/3 拒，12 字，逐字相同**。

合并三轮：**拒答 8/8 全部以那句固定串开头**；正常回答 3 条，**0 条**含它。

## 三 · 🔴 为什么**不是**「加相似度下限」（一条被实测判死的路）

开工前的想当然是：「库里没有 ⇒ 检索相似度低 ⇒ 设个阈值，低于就拒」。
**第 2 轮的数据把它判死了，而且不是"阈值定得不好"，是结构性的：**

> `净利润` 和 `营收` 这两个问题**打进的是同一篇** `financial_report`，**相似度几乎一样** ——
> 一个该答、一个该拒。
>
> ⇒ **相似度量的是「问题 ↔ 文档」的距离，量不了「事实 ∈ 文档」。**

**任何**基于相似度阈值的拒答门，都会在「同文档邻居问题」上失效。
⚠️ 而这类问题正是**最该被拦住**的：用户问的是一篇他刚上传的文档的细节，模型手上有"很像"的材料 ——
**这正是最容易编一个数的场合**。

📌 **顺带一条方法论**：如果只跑第 1 轮就下结论，阈值会定在 0.3 附近，**看着很稳**。
是"把题目换成相邻的"这一步把假象戳破的。⇒ **测拒答，题目必须包含"同文档邻居"。**

## 四 · 那剩下的问题是什么（= 这一件真正要做的事）

8/8 在拒，但它**只活在正文里**，三个消费者都够不着：

| 消费者 | 今天拿不到什么 |
|---|---|
| **前端** | 拒答与普通回答是**同一句普通文字** —— 画不出区别；而且实测有一条拒答**后面挂着 3 个可点来源号**（一边说"答不了"、一边给来源，**自相矛盾**） |
| **评测** | `bad_cases.md` 正记着「**评估集缺拒答类样本**」—— 没有信号就刷不出样本 |
| **日志 / 运营** | 「拒答率」这个数**今天根本不存在** |

⇒ **这一件补的是【可观测性】，⛔ 不是【拒答率】。**
prompt / 模型 / 检索**一行不动**，⛔ 不引入二次 LLM 判定，⛔ 不加相似度阈值。

## 五 · 实施

### 后端 · `api/api_v1_rag.py`（2 处 / 约 6 行）

```python
REFUSAL_SENTENCE = "根据现有资料，无法回答"     # 模块级常量
```

**为什么要抽常量**：这句话原先**只**在 prompt 的 f-string 里。现在多一个消费者（判据），
两处**必须一致**，而它们分家的表现是**静默的** —— prompt 换了措辞 ⇒ 判据认不出来 ⇒
`no_answer` 帧永远不发 ⇒ **页面上只是一句普通回答，没有任何报错**。
⇒ **prompt 与判据共用同一个常量**，从结构上排除漂移（本仓「两处各写一遍 ⇒ 静默漂移」那一族）。

收尾（`_complete`）里：

```python
yield DONE_FRAME
if "".join(collected).lstrip().startswith(REFUSAL_SENTENCE):
    yield sse_frame({"no_answer": True}, ensure_ascii=True)
```

**帧序：`content… → [DONE] → `no_answer` → sources → usage`**
放在 `[DONE]` 之后、`sources` **之前** —— 它描述的是**刚结束的那段答案**；而 `sources` 那一趟
前端会重画，**标志先到，那一趟才能一次画对**。⛔ 别挪到 `usage` 后面。

⚠️ **对老前端天然兼容**：`sse.js` 的 `payloadKind` 认不出的帧落到 `'unknown'`，
而 `chat.html` 对 `'unknown'` **什么都不做** ⇒ 后端加帧不会让旧页面出任何错。

### 🔴 判据是「**以它开头**」，⛔ 不是"含"（一处**有意**的取舍）

依据：实测 **8/8** 模型都把它放在**开头** —— 与 prompt 里那句「请**直接说**…」相符。

| 走哪边 | 漏判 | 误判 |
|---|---|---|
| 用 `in`（含） | 少 | **多** —— 句中一提就被判成拒答 |
| **用 `startswith`（本刀）** | 稍多 | 少 |

⇒ **选 `startswith`：误判比漏判有害**（把答得好的那轮画成"资料里没有"）。
**代价写实**：换过措辞的拒答（如「文档未提及净利润，因此无法回答该问题。」）**会被漏掉** ——
但那只是**退化成今天的样子**，⛔ 不会更糟。

### 前端 · 纯逻辑进 `sse.js`，DOM 留在 `chat.html`

* `sse.js`：`payloadKind` 多认一种帧 + `refusalNotice()`（文案，照 `DEC-090` `breakerCard` 的样）
* `chat.html`：收到帧 ⇒ `turn._refused = true` ⇒ `renderAnswer` 转走 `renderRefusal`：
  **正文不切引用**（那条路上引用是矛盾呈现）· 画提示条 · 卡片一定是收着的

🔴 **判据（「这轮算不算拒答」）只有后端那一份** —— 前端**只认帧**。
起草时曾在选项里写过 `sse.js isRefusal(text)`，**当场撤了**：那是把判据抄两份，
正是本仓反复钉的「两处各写一遍 ⇒ 静默漂移」。现在有一条**结构型用例**盯着这件事。

⚠️ 提示文案的两条硬约束（都有用例钉着）：① 必须指向**"资料/文档"**（说成"出错"会让人去重启/找人修）；
② ⛔ 不许暗示"稍后再试"（那是**限流**那种状态的出路，`breakerCard` 管的是另一件事）。
⚠️ ⛔ 也**不许**说「检索不到片段」—— 那是**假话**：实测拒答那一轮 `sources` 帧里**照样有 3 条**。

## 七 · 施工时真栽的两下（都记下来）

**① 注释里抄了被守卫禁的子串 —— 同族第 4 次。**
我在 `chat.html` 的注释里写了「见过「根据现有资料，无法回答。…[来源:1, 2, 3]」」**作为例证** ——
而那正是新建的结构型守卫要数的子串 ⇒ **守卫立刻红了，抓的是我自己**。
⇒ 改法：那条注释改成**不出现该串**的描述（「见过一条拒答后面挂着 3 个可点来源号」）。
⚠️ 本仓同族前科：`DEC-090` §六（注释里抄了被禁子串）、`DEC-089`（旧注释里的词被判据当"还没修"的标记）。

**② 尺子误伤了真话 —— `refusalNotice` 那条守卫第一版是错的。**
第一版写 `/稍后|再试|重试|刷新/`，而提示文案里「先上传相关文档**再试**」**是做得到的出路**。
⇒ 那是**尺子歪了，不是文案错**：本条的靶子是「等一会儿它自己就好了」那个**假承诺**，
⛔ 不是"再试"这两个字。收窄成 `/稍后|重试|刷新|多试|过一会儿|等一会/`。
📌 **判据**：一条守卫若把**真话**判成违规，先审**尺子**，别急着改文案。
