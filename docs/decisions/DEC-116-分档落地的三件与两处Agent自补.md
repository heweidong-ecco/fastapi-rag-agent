## 一 · 要解决的是什么（一行）

`api/api_v1_rag.py` 的上传端点原文只有一句**按扩展名猜**：

```python
doc_type = "legal" if ext == "pdf" else "technical"
```

⇒ **除 PDF 外的一切（`.md` / `.docx` / `.html`）全吃 `technical`（原 500/50）**
⇒ `report` / `article` **从来用不上**；而 FAQ 的问答对（140–300 字）**会被合并进 500 的块**
⇒ 检索命中的是「**四五对问答的混合体**」。

✅ **业务方 2026-10-08 裁的**：「上传接口加一个**可选** `doc_type` 形参，
**默认 = 现有推断 ⇒ 访客行为一字不变**；我们的灌库脚本可显式给。」

## 二 · 🔴 本 DEC 里【哪些是业务方裁的、哪些是本 Agent 补的】（⛔ 别混）

| # | 做了什么 | 谁定的 | 为什么补 |
|---|---|---|---|
| **①** | 上传接口加**可选** `doc_type` 形参；**不传 = 沿用扩展名推断** | ✅ **业务方原话**（`N19` 裁定） | — |
| **②** | 🔴 **未知档位 ⇒ 400**（`AppException(PARAM_INVALID)`） | 🔴 **本 Agent 补的** | `chunker.get_text_splitter` 是 `CHUNK_CONFIGS.get(doc_type, default)` ⇒ **静默回落**。一个拼错的 `"techincal"` 会让**整批语料**按 500/50 切，**不报任何错**。本仓立场「**响亮 > 静默**」（`DEC-051` 那族）。<br>⚠️ **代价认了**：多了一条**对外承诺**（加了的参数/报错就删不掉） |
| **③** | **新增 `faq` = 300/50** | 🔴 **本 Agent 补的** | 🔴 **没有它，① 对 FAQ 就是空的** —— 形参能传 `"faq"`，但表里没这一档 ⇒ 传了也是回落 `default`。业务方的裁定**只说了"怎么指定"，没说"档位有没有"**。<br>📄 依据（8 份来源的 FAQ 值 100–200 token ≈ 140–300 中文字）⇒ `docs/说明/语料要求.md` §5.4 |

## 三 · 为什么【三件一起做】而不是只做 ①

🔴 **只做 ① 会留下两处半截**：
* **没有 `faq` 档** ⇒ 形参对 FAQ 无效（传了回落 `default`）
* **没有 ② 的校验** ⇒ 形参**写错不报错**，而它正是**灌库脚本唯一的入口**

⇒ 本仓立场：**「配置表看起来比实际能力大」是缺陷**（`docs/specs/chunker.md` 原话），
不是"以后再补"。⇒ **一次做完，不留半截。**
