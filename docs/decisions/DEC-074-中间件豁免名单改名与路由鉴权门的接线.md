## 一 · 病：**两条，重症程度完全不同**

### 1.1 变量名在撒谎（轻，但会误导人）

```bash
grep -n 'MIDDLEWARE_EXEMPT_PATHS = frozenset' -A 5 api/main.py
#   ⇒ "/api/v1/admin/create_user" 在这个名单里
grep -n 'require_admin' -B2 -A2 api/api_v1.py
#   ⇒ :161  async def create_user(req: UserCreate, user_name: str = Depends(require_admin))
#   ⇒ 非管理员 **403** —— **它在"公开名单"里，却要管理员**
```

⇒ 旧名 `PUBLIC_PATHS` 表示的是「**公开**」，而它的真实语义是
「**跳过限流 / 配额这两个中间件**」。**与"该端点要不要鉴权"完全无关。**

⚠️ 而且这不是论文级的歧义 —— `docs/specs/main.md:42` **早就写对了**：

> 「`PUBLIC_PATHS` 里的路径 = 不需要登录」 ⛔ **不是**。

⇒ **正确的解释躺在 spec 里，而误导的名字挂在代码上。**
代码是被读得更多的那一侧 ⇒ **名字得改**。

### 1.2 🔴 守卫一直没接线（重，是那条「门挂在别处」的又一例）

```bash
grep -n 'check_route_auth' .github/workflows/*.yml scripts/ci-local.sh \
                            .claude/hooks/pre-commit-gates.py
#   ⇒ ❗ 三处都没找到（改动前）
```

而它**别的地方全齐**：脚本有（2026-09-30 建的）· 基线有 · `开发规范` §1.5 有 ·
提醒 hook `.claude/hooks/route-auth-remind.py` 也有，**且已注册** `.claude/settings.json:29`。

⇒ **它只在"Claude 会话里改路由文件"时提醒一句。**
⇒ `git commit` 不跑它、CI 不跑它 ⇒ **忘了就没有任何东西会响。**

> 这正是本仓自己那句：**「门挂在别处，就等于没有门」**（`2026-09-16-八个PR跳过了留痕门`）。
> ⚠️ 与我**上一轮**的建议对照：我当时提议「新写一条守卫」——
> **核查后发现东西早就有，缺的只是接线** ⇒ 改成了接线，⛔ 没有重复造。

### 1.3 🆕 顺带核出：那个守卫**看不见 WebSocket**


**但写在文字里 ≠ 有门**。⇒ 本轮把它做成结构（见 §三·3）。

⚠️ 为什么这重要：`/api/v1/ws/agent` 是**真花钱**的（跑 agent executor），
且**整条没有鉴权**（`DEC-041` 遗留·1）。它此前在一份「无鉴权路由清单」里
**连一行都占不到** —— 清单"干净"得看不出问题。

## 二 · 改名：`PUBLIC_PATHS` → `MIDDLEWARE_EXEMPT_PATHS`

**为什么取这个名字**：它逐字描述了这个名单**唯一的**效果 ——
「这些路径**跳过限流/配额两个中间件**」。⛔ 不含任何关于"公开 / 鉴权"的暗示。

- **零行为变更**：只改标识符与注释，两个中间件的判断逻辑一字未动。
- **同步改的**：`api/main.py`（定义 + 两处引用）· `api/test_public_paths.py` · `scripts/check_route_auth.py`。
- **⛔ 没改的**：`docs/decisions/` 与 `CHANGELOG.md` 里**历史记录**中的旧名
  —— 那是**留痕**，改写它等于篡改当时的记录。⇒ 本条 DEC 就是旧名→新名的对照。
- ⚠️ **代价（知道再选）**：`grep PUBLIC_PATHS` 现在**查不到代码里的东西了**。
  缓解 = 新名字的注释里**逐字写出旧名**（`api/main.py:103`），
  且本条 DEC 可被搜到。

## 三 · 接线：三处，都是**结构**不是文字

### 3.1 CI（`.github/workflows/ci.yml`）

加进**跑 pytest 的那个 `run` 块**，排在其**前面**：

```bash
PY_ROUTE=python
if [ -x venv/bin/python ]; then PY_ROUTE=venv/bin/python; fi
"$PY_ROUTE" scripts/check_route_auth.py --baseline
```

- **为什么排在 pytest 前面**：`run` 块是 `bash -e` 语义，**先红的那条会吃掉后面**。
  pytest 动辄几分钟且本仓红过多次 ⇒ 放前面才能保证这条**一定被跑到**。
- ⚠️ **只改 ci.yml，⛔ 不用改 `ci-local.sh`** —— 它是**整块照抄** `ci.yml` 的 `run`
  （`ci-local.sh:136` 找含 `pytest` 的 step，取整块执行）⇒ **自动跟上**。
- 🔴 **两个写错过的形态**（都记在 ci.yml 注释里，别改回去）：
  ① `venv/bin/python … || python …` —— 检查**失败（exit 1）时会掉进第二个解释器再跑一遍**，
     把红灯洗成绿灯；
  ② `[ -x … ] && PY_ROUTE=…` —— 本块在 `-e` 下，条件为假**整条 AND-list 返回非零 ⇒ 脚本当场退出**。

### 3.2 提交门（`.claude/hooks/pre-commit-gates.py`）—— 第 ⑤ 道

| 状态 | 条件 | 行为 |
|---|---|---|
| ⏭ 跳过 | staged 里**没有** `api/**.py` 的产品文件 | 不跑（省掉 ~10s） |
| ✅ / 🔴 | 有 ⇒ 跑 `--baseline` | exit 0 过 · 非 0 **拦** |
| ⚠️ 跳过 | 脚本不在 / 跑不起来 / git 读不到 staged | **放行**（同「四条克制」②：门坏了自己不该把人锁死） |

🔴 **触发条件取"范围"不取"名字"**：
提醒 hook 那边写的是 `ROUTE_FILES = {"main.py","api_v1.py","api_v1_rag.py","api_v1_agent.py"}` ——
**新建一个 `api/api_v2.py` 就整个漏掉**（`DEC-066` 那个形状）。
⇒ 这里用 `api/**.py`（排除 `test_*` / `conftest.py`），**不留那个形状**。
📌 自证（6 例全过），含：

```
✅ 新文件 api_v2.py 也必须触发（旧提醒 hook 就漏这个）
✅ git 失败 ⇒ None（⚠️ 不是「空」）—— 同第 ④ 道门那次的教训：别把故障说成正常
```

### 3.3 扫描口径：WebSocket 也收（`scripts/check_route_auth.py`）

- `_collect_apiroutes` → **`_collect(routes, http, ws)`**：多一个出口收 `APIWebSocketRoute`。
- 新增**纯函数** `find_routes_without_auth(routes, exempt_paths)` ——
  `scan()` 与 pytest **共用同一份判据**（⛔ 不抄第二份：`DEC-051`「一个名字两个来源」）。
  ⚠️ 它**不 `chdir`**（脚本的 `scan()` 有 `os.chdir`，在 pytest 进程里调会**污染整个会话的工作目录**）。
- WS 行的方法标签是 **`WS`**（⛔ 标 `GET` 会让人以为它是个 HTTP 端点）。
- 基线 1 条 → **3 条**，头注里写清那两条 WS 各自的理由。

## 四 · 判据（可打印）

```bash
venv/bin/python -m pytest api/test_route_auth_scan.py api/test_public_paths.py -q
#   ⇒ 15 passed（9 + 6）

venv/bin/python scripts/check_route_auth.py
#   ⇒ 真实路由总数：60（HTTP + WS）· 🔴 无鉴权路由：3 条（HTTP 1 · WS 2）
#      GET /api/v1/ · WS /api/v1/ws/agent · WS /api/v1/ws/test

venv/bin/python scripts/check_route_auth.py --baseline ; echo $?
#   ⇒ ✅ 与基线一致。   exit 0
```

**变多时必须真的红**（⛔ 不能只看 ✅ 那一次）：

```bash
# 造一条无鉴权路由 → 跑门 → 应当 exit 2 并点名它 → 复原
# 实测输出（摘）：
#   ❌ 比基线【多了 1 条】—— 新引入了没鉴权的路由：
#        + /__selfcheck_no_auth__
#   exit=2
```

**提交门自证**（喂 hook JSON，看它跑没跑）：三种状态各验过 ——
`api/*.py` staged ⇒ `路由鉴权门 ✅` · 非 commit 命令 ⇒ **stderr 空、exit 0** ·
git 失败/脚本不在 ⇒ `⚠️ 跳过` 且**放行**。

⚠️ **踩过的坑（写在这里省下一次）**：验这道门时，**我自己的测试命令里字面写了
`git commit`** ⇒ **hook 把我那条 Bash 命令本身拦了**（它匹配的是命令串，不看上下文）
⇒ 前半截 `cp` 没执行、探针留在文件里。
**判据**：验这道门时，别在命令串里写那两个字（拼字符串 / 用变量）。

## 五 · 代价与反悔成本

**代价**
- 提交门每次**多 ~10s**（实测 `9.95s`），条件是本次动了 `api/*.py` —— **本仓多数提交都会动**。
  ⚠️ 这是**有意拿时间换"不会被忘"**；真正的兜底是 CI（无条件跑）。
- 基线 1 → 3 条：**多出来的 2 条是"债"，不是"批准"** ——
  ⛔ 别把基线读成允许清单（文件头注已写明）。

**反悔成本**：**低**。
- 退改名 = 反向 sed（但会退回那个误导的名字）。
- 退接线 = 从 ci.yml / hook 各删几行，**脚本与基线原样保留**。

## 六 · 备选方案（⛔ 都没采纳）

| # | 方案 | 为什么否 |
