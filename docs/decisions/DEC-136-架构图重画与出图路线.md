## 一 · 为什么旧图必须重画（**不是"旧"，是"错"**）

`docs/原理/架构.md` 自己记着一条：

> ⚠️ **一处已过时，别照图核代码**：图上工具层画的是 **`rag_search`**，
> 而**当前的实际工具是 `fetch_webpage_html`** ⇒ 这张图记录的是**更早一代**的工具集。

⇒ 🔴 **图比文字更容易烂**，而且**烂了没有门会红**（断链门查路径存在性，⛔ 不查"图上画的对不对"）。

---

## 二 · 🔴 决策点 1 · **出图走哪条路**（**本 DEC 唯一真分叉**）

**本机实测**：`dot` / `neato` / `mmdc` / `rsvg-convert` / `convert` **全部没有**；
Python 侧只有 **`matplotlib` 3.10.9** + **`PIL` 12.3.0**；**Playwright MCP 可用**。

| 备选 | 评估 |
|---|---|
| **甲 ✅ 写 HTML + CSS ⇒ Playwright 截图** | ⛔ **不引入任何新依赖**；**中文 / 排版 / 配色全可控**；改一行 CSS 就重排。<br>⚠️ 代价：**本机出图是 Agent 用 MCP 做的，没有 CLI 脚本**（见 §四） |
| 乙 `matplotlib` 画框 | 要在代码里手算坐标 ⇒ **改一个字都得重排**；中文还要额外配字体 |
| 丙 装 graphviz / mermaid CLI | ⛔ **为出图给本机加依赖** —— 与本仓「**⛔ 别往 requirements 塞 linter**」同一条线：**出图工具不该进产品依赖面** |

**选甲**。📌 **实测截图产出 180–230 KB/张**（旧那张 `architecture-full.png` 是 **1.5 MB**）。

---

## 三 · 决策点 2 · **图源要不要入库**

| 备选 | 评估 |
|---|---|
| **甲 ✅ 入**（`docs/原理/图源/*.html`） | 图**能再生成** —— 内容变了改 HTML 重出即可，⛔ 不是"手画完就没人会更新"的位图 |
| 乙 只入 PNG | PNG **改不动** ⇒ 下次要改只能**重画一张**（而重画的人**不会知道上一版画了什么**） |

**选甲**。⚠️ **代价**：新目录 ⇒ **必须建 `CLAUDE.md`**（分层门会硬拦）—— 已建，含**三步重出图**的做法。

---

## 四 · ⚠️ 一处要说清的边界

🔴 **出图【没有 CLI 脚本】** —— 因为**出图工具是 MCP（Playwright），不是命令行**。
⇒ `docs/原理/图源/CLAUDE.md` 里写的是**三步做法**（起回环服务 → 打开 HTML → 截图存盘），
**要重出图就让 Agent 照做**，⛔ 不是 `bash xxx.sh`。

⚠️ **另有一条坑**：浏览器**挡 `file://`** ⇒ 必须先起一个 **`--bind 127.0.0.1`** 的静态服务（⛔ 别用默认的 `0.0.0.0`，那会把目录暴露到局域网）。
