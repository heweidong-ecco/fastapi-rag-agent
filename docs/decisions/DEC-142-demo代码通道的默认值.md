## 一 · 裁的是什么（**三句**）

| # | 说 |
|---|---|
| **1** | ⭐ **默认 = 完整版** —— **不设任何环境变量时走 PostgreSQL**，行为与今天**逐字一致**。 |
| **2** | 🔴 **demo 那条通道必须由【显式开关】开启**（开关名由「`①b` 命令级施工单」定）。 |
| **3** | 🔴 **同时配一条「两种取值各跑一遍」的守卫**，而且**必须走子进程** —— 模块级变量在同进程里改环境变量**静默无效**（本仓踩过）。 |

**为什么要有这三句**：它们回答的是那个追问 —— **"别人 clone 本仓、拿本仓的代码去用，会拿到哪一份？"**
⇒ 按这三句，**拿到的是完整版**；demo 那份要**自己去开开关**。

## 二 · 为什么【必须现在裁】（⛔ 别留到 `①b` 开工时再想）

| # | 理由 | 依据 |
|---|---|---|
| 1 | 🔴 **它是"clone 的人拿到什么"的唯一开关** —— 不定它，这件事就是悬的 | 业务方 2026-10-10 的追问 |
| 2 | 🔴 **不定它，`DEC-098 §7.1` 那条验收做不到** —— 那一节要求「**契约测试必须同时打 PostgreSQL 和 SQLite，两个后端各跑一遍同一组用例，`passed` 数可拆开**」⇒ **两个后端必须都活着** | `DEC-098 §7.1` · §四·4.2 第 1 条 |
| 3 | 🔴 **不定它，`①b` 会写歪** —— 改动面**至少 6 个文件 · 8 张表的建表语句散在 3 个模块**（`DEC-098 §二·2` 的实测）；这么大的改动面，**"改掉"和"加一条通道"是两种写法**，落笔时再纠就晚了 | `DEC-098 §二·2` 复核块 |

⚠️ **还有一层**：这条**此前全仓没有任何记载** ——

## 三 · 备选与评估（**四个，只有一个采纳**）

**评估标准三条**：① **clone 的人拿到哪一份** ② **`DEC-098 §7.1` 那条"两个后端各跑一遍"能不能做到** ③ **漂移面有多大**。

| 备选 | ① clone 拿到 | ② 两后端各跑一遍 | ③ 漂移面 | 结论 |
|---|---|---|---|---|
| **甲 ✅ 加一条 SQLite 通道，默认仍走 PostgreSQL** | **完整版** | **能做** | 小 —— **一条分支**，且**两个方向都有守卫** | ✅ **采纳** |
| 乙 直接把 `app/core/db.py` 改成 SQLite（不保留 PG 通道） | 🔴 **demo 那份** | 🔴 **做不到** —— `§7.1` 当场红 | 小，但**代价错**（把"完整版"换掉了） | ⛔ 否 |
| 丙 全 SQLite（连令牌桶 / 缓存 / 改写器一起） | demo 那份 | 做不到 | **大** —— 多动 3 个文件 | ⛔ 否（`DEC-098 §三·3.1` 的 A 方案**早已否掉**） |
| 丁 在 `demo/` 下另写一份独立代码 | demo 那份 | 做不到（那份不在镜像里） | 🔴 **最大** —— 两份实现必然漂移，而**门扫不到 `demo/`** | ⛔ 否（`DEC-141 §3` 已否） |

> 📌 **丁那条为什么单列**：业务方 2026-10-10 亲口问过「**不能给它单独写独立的代码吗，
> 或者单独只是映射给 demo，放在 `demo/` 文件夹下**」⇒ 这一格是**他当时那个问题的正式答复**，
> ⛔ 别让下一个人再问一遍。

## 四 · 这条**不改**什么（⛔ 别读成"demo 不能专有行为"）

🔴 **它只钉"默认走哪条"，⛔ 不是"不许有 demo 专有行为"。**

| | |
|---|---|
| ✅ **demo 专有的行为，本仓已经有了** | `app/tools/mcp_server.py:85` 的 `DEMO_MODE` —— demo 下 `execute_python` **不注册**（demo 单容器 ⇒ **没有第二个容器**能跑执行器 ⇒ 宁可**不给**，也不回落到宿主） |
| ✅ **它为什么是安全的** | 它是**环境变量门控**的 ⇒ **不设它 = 拿到完整版** ⇒ 正是本文第 1 句要的形状 |
| ⚠️ **它同时是那句话的现成样板** | 「一处分支 + **两条**守卫（`test_tool_registry_single_source.py`，走子进程）」—— 本文第 3 句要求的就是这个形状 |
| ⛔ **它不是说"凡有差异都加开关"** | 判断标准是「**两处行为是否确实该不同**」——《`/debug/*` 那四条**没有**不同，所以**不加**开关》（见 `DEC-141 §3.2`） |
