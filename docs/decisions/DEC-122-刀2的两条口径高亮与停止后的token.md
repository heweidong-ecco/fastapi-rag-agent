## 二 · 被裁的那一条

> **业务方 2026-10-09 选择：两条都选「甲 · 认下现做法」**（本 Agent 给的推荐）。

### 2.1 §7.1① ⇒ 高亮「**答案与原文逐字重合**的片段」

- **实现**：`RagSse.overlapRanges(原文, 答案, 6)` —— O(n·m) 最长公共子串扫描，
  长优先、取**互不重叠**的若干段。页面用 `createElement`/`textContent` 拼 `<mark>`（⛔ 不用 innerHTML）。
- 🔴 **它⛔ 不是"服务端给的命中区间"** —— 它是一句**算得出来、且能自证**的话：
  「**这几个字确实是从这段原文里来的**」。访客点开就能看出这句话有没有根据。
- ⛔ **找不到重合 ⇒ 一个字都不标**（不假装高亮了一段）。
- ⚠️ 阈值 **6 个字**：再短会把「保修期」这种词标得满屏黄。

### 2.2 §7.1② ⇒ `已生成 N 字 · 中断未计费（取消时那一帧 usage 到不了）`

- **实现**：`RagSse.stoppedNotice(answer)`。
- 只给**说得出处**的两样：**本地数得出的字数** + **未计费是事实**，并**写明原因**。
- 🔴 **⛔ 别"顺手"改成 token 数** —— 那会让人以为这一轮花了钱，而账上根本没有那一笔。
