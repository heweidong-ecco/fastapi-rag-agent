## 二 · 决策点（**逐条给备选与理由**）

### 2.1 容器名 —— **保留 `api/`**

| 备选 | 判断 |
|---|---|
| **`api/`（选）** | 语义正确：本仓是**一个可部署服务**（一个镜像、一个 `uvicorn` 入口），`api/` 就是服务根。**且已经存在 ⇒ 改名成本 0** |
| `packages/`（任务书原文的建议） | ⛔ **名不副实** —— `packages/` 的语义是「**多个可独立构建/发布的包**」，本仓是**一个** |
| `src/` / `backend/` | ⛔ 同级的改名成本，且 `backend/` 会误导（本仓**没有** `frontend/` 代码，真前端在 `api/static/`） |

**改名代价（实测）**：Docker 构建上下文 **2 处**（`docker-compose.yml`）· `dev.sh` · `ci.yml` **16 处** ·
`scripts/` **8 个脚本** · `.claude/` **3 个 hook** · `ruff.toml` · `alembic.ini` · `.gitignore`。
⇒ 改名 = 把这次的代价**翻一倍**，换来一个更差的名字。

### 2.2 **不套 `src/`**

三条理由（实测）：
1. **`src/` 要解决的问题本仓没有** —— 它的用途是「要 `pip install` 这个包，防测试误 import 源码目录」。
   本仓实测 **`__init__.py` 0 个 · `pyproject.toml` 0 个 · `setup.py` 0 个** ⇒ **不安装、不发布**。
2. **多一层而没有任何东西按它分隔** —— 各模块组**不是**独立构建 / 独立测试 / 独立发布。
3. 🔴 **最硬**：`Dockerfile` 是 `WORKDIR /app` + `COPY . .` + `CMD uvicorn main:app`，
   构建上下文 `./api` ⇒ **容器内 `/app` 就是 `api/` 的内容**。插 `src/` 要改 `CMD`、重算 `sys.path`、
   重推 **30 个用 `Path(__file__)` 算仓根的测试** —— 全是成本，且**每一处都能静默坏**。

### 2.3 七个模块组（+ `eval/` + `tests/`）

`core`(8) · `routing`(7) · `access`(5) · `billing`(4) · `agent`(9) · `rag`(10) · `tools`(13)
—— 判据是**依赖图**（`token_tracker` fan-in 16 · `config` 12 · `db` 11 · `llm_factory` 8）。

⚠️ **`api/` 根只留 2 个 `.py`**：`main.py`（`uvicorn` / `CMD` 绑它）与 `conftest.py`
（⭐ **它一留，`api/` 就在 `sys.path` 上 ⇒ 搬进 `tests/` 的 94 个用例仍可用裸导入**）。

### 2.4 import 写法 —— **绝对写法，根 = `api/`**

| 备选 | 判断 |
|---|---|
| **`from core.config import X`（选）** | `api/` 已在 `sys.path`（`conftest.py` + `pytest.ini` 的 `pythonpath`）；⛔ **不需要 `__init__.py`**（Python 3 命名空间包）；文件仍可被 `python xxx.py` 直接跑 |
| `from ..core.config import X` | ⛔ **直接当脚本跑会失败**（`mcp_server.py` / `executor_server.py` 会），且报错难懂 |
| `from api.core.config import X` | ⛔🔴 **容器里 `/app` 就是 `api/` 的内容** ⇒ 没有 `api.` 这一层 ⇒ **线上必 ImportError** |

### 2.5 其余四项（业务方 2026-10-09 逐个裁的）

| # | 事项 | 裁决 |
|---|---|---|
| ⓐ | `locustfile*.py` 放哪 | **仓库根 `locust/`** —— ⛔ 否决了「`api/locust/`」（`api/` 是构建上下文 ⇒ 会进镜像，而镜像里**故意没装 locust**，见 `DEC-034`） |
| ⓑ | `api/static/` 搬进 `frontend/` 吗 | **⛔ 不搬**（维持 `DEC-120 §七`，第三次同裁） |
| ⓒ | `preprocess.py` | **删** —— 它是 25 行硬编码 `print` 脚本、零函数零调用方；真功能 `DocumentPreprocessor` **已在产品模块**里且被上传链路真调用 |
| ⓓ | `prompt/`（0 文件空目录） | **删** —— git 不跟踪空目录，它在库里**从来不存在** |

### 2.6 每层目录一份 `CLAUDE.md`（段 3，⬜ 未做）

**性质变了**（业务方原话）：
> 「每个文件夹下的 `CLAUDE.md` 就是**索引表**和**主要内容**，**渐进式披露** ——
> agent 进来，**从入口进来必须先看 `CLAUDE.md`**，**信息不够，需求再转**。」

⇒ ⚠️ **不是**「模块规则」，是**该层的入口页**。共 **53 份**（仓库根 1 + 树内 52）。

## 四 · ⚠️ 这次修掉的 6 类「静默坏」（**这类不报错，只出错**）

| # | 症状 | 为什么会静默 |
|---|---|---|
| 1 | **10 个测试用 `glob("*.py")` 扫 `api/`** | 挪进子目录后**扫到 0 个文件**，而**空集合断言恒为真** ⇒ 已改 `_product_py()` 递归 + **防空跑断言** |
| 2 | `mcp_server.py` 被**当脚本**跑 | `sys.path[0]` = `api/tools/` ⇒ `from tools.*` 解析不到 ⇒ 已加 sys.path 引导 |
| 3 | `config.py` 的 `.env` 推算 | 挪进 `core/` 后读 `api/.env`（不存在）⇒ 落到代码默认值，**不报错** ⇒ 上溯两层 |
| 4 | `logger_config` 的 `logs/` · `browser_tools` 的 `screenshots/` | 同型（写进别的目录，不报错） |
| 5 | `__import__("agent.agent_graph")` | 返回**顶层包** `agent`，不是子模块 ⇒ 改 `importlib.import_module` |
| 6 | `agent_graph_advanced` 用 `with_name("mcp_server.py")` | 两者已不同组 ⇒ 改显式路径 |

📌 **同族教训已记多次**（`docs/复盘/2026-10-05-拿代理量当判据.md` 等）——
⇒ **本次的应对是**：改完**先跑**，让 913 条用例与 6 道门当尺子；⛔ 不靠"我改对了"。

## 五 · 备选方案（**整体**）

| | 备选 | 评价 |
