## 三 · 决策内容

### 3.1 清单从 `mcp_server.TOOLS` **派生**（四处）

```python
from mcp_server import TOOLS as _MCP_TOOLS
tools = [t["func"] for t in _MCP_TOOLS]
```

### 3.2 定义只留**正本**

| 工具 | 唯一的定义处 |
|---|---|
| `calculator` · `date_today` | `api/simple_tools.py` |
| `web_search` | `api/search_tools.py` |
| `execute_python` | `api/code_executor.py` |

删掉的 4 份副本：`agent_graph` · `agent_checkpointer` · `agent_graph_advanced_learning` ·
`tools_with_cache`（整个模块）。

### 3.3 🔴 **可见行为变更**（工具 schema 变了，⛔ 必须显式声明）

| 变更 | 影响 |
|---|---|
| `calculator` / `date_today` 的 **docstring 换成 `simple_tools` 那份**（更详细：多出「输入的必须是纯数学表达式」/「忽略查询参数」） | LLM 读到的工具描述变了 |
| `api_v1_rag` 的工具名 **`search` → `web_search`** | ⚠️ **名字变了** —— 现在与 `SENSITIVE_TOOLS` 默认值一致（改前那个 `search` 在审批白名单里**根本对不上**） |
| `agent_graph` / `agent_checkpointer` 的工具表**仍是 3 个**（`execute_python` 被排除） | 与改前**条数一致** ⇒ 这两张图的行为**没变** |

🔵 **端到端实证**（§五 ④）：真起服务、真打 `/api/v1/ws/agent`，三个壳**各验一次**。

### 3.4 🔴 `api_v1_rag` **保留 async 外壳** —— ⛔ 不能直接换成 `mcp_server` 那份

原文是 `async def` + `return await asyncio.to_thread(...)`，**有意把阻塞丢出事件循环**。
`mcp_server` 那份是**同步**的 ⇒ 直接替换会**在事件循环里同步跑 20 秒的网络调用**。

⇒ 用 `StructuredTool.from_function(coroutine=…, name/description/args_schema=取自共享工具)`：
**实现与描述都收口了，异步性也保住了**。

### 3.5 ⚠️ `execute_python` **暂排除**于 `agent_graph` / `agent_checkpointer`

那两张图里它**既不在** `SENSITIVE_TOOLS` 审批名单、**又没有**容器隔离
⇒ 放进去等于开一条**无审批 + 无隔离**的任意代码执行。

🔴 **业务方 2026-10-08 对此明确答「待定」** ⇒ **本批按保守办**（排除），等批② 容器落地再放开。
守卫：`test_tool_registry_single_source.py::test_agent_graph_tools_exclude_execute_python`。

### 3.6 🔴 安全守卫面 **5 处 → 1 处** —— 且**不是"放宽断言"**

`api/test_safe_math_wiring.py` 原先按**名字**钉死 5 个 `calculator` 站点。
删掉 4 份副本 ⇒ 守卫面必须同步收窄，**否则"删文件"会悄悄把守卫的面缩了、而没人记得说过**。

⚠️ 本条规矩（批① 施工单原文）：**每删一个站点，就要能说出「它原来守的能力现在由谁守」**。

| 删掉的站点 | 现在由谁守 |
|---|---|
| 三张图各一份 | ⭐ **它们拿到的就是 `simple_tools` 那一个对象** ⇒ 守 `simple_tools_impl` **= 守它们**<br>📌 **有判据，⛔ 不是嘴上说**：`test_all_graphs_share_the_same_tool_objects` 用 **`is`（对象同一）** 断言 |
| `tools_with_cache.calculator` | 模块**整个删了**（见 §3.7） |

### 3.7 `api/tools_with_cache.py` **删除** —— 业务方 2026-10-08 当场裁定

> 原话：「**`tools_with_cache.py`，删除，这是定好的事了，这个是重复的，没用了**」

**现在批① 已经把缓存接在【工具函数体】上**（`DEC-106`）⇒ 它成了纯重复，挂起的理由消失。

## 六 · 边界

1. ⛔ **新工具要加两处**：`mcp_server.TOOLS` 加一行 + `test_tool_registry_single_source.py`

2. ⛔ **别再往 `OFFLINE_SITES` 加模块名** —— 那意味着又有人抄了第 N 份 `calculator`。

   语义不同：前两个是**分派表**（`test_tool_dispatch.py` 守），第三个只是**按名字取对象**。
