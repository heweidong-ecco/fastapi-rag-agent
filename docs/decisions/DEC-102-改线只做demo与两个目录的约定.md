## 二 · 两个目录：**用途相反，git 待遇相反**

> ⚠️ **它们【同级】、都在仓根。** ⛔ 别把一个当成另一个的子目录。

| | **`demo/`** | **`未进demo/`** |
|---|---|---|
| 是什么 | **正在做 Demo 的工作区**（施工现场） | **已完成 · 可用 · 但没能进 Demo** 的代码 / 文档（完工存量） |
| 会变吗 | 会（乱、随时改） | 不会（稳定、要给人看） |
| git | ⛔ **已 gitignore**（`.gitignore:63` ⇒ `demo/`） | ✅ **入库** |
| 权威内容 | 「**demo清单**」（业务方写的 11 项）·「**待办-demo之后**」（`B14`）· **探针**（见 §三） | `README.md` **本身就是它的规矩** |

### 2.1 为什么 `未进demo/` 要**入库**（而 `demo/` 不入）

> **业务方原话**（2026-10-07）：
> 「**未进demo/ 可以提交，让 clone 的人能知道这些是可用的，这是已完成的功能，不进 .gitignore**」

**目的**：让 **clone 的人**看得出「**这个仓还做过这些**」——
⛔ **而不是**把"没进 Demo"读成"没做"。

### 2.2 🔴 铁律：**只进不出 · 永不删除**

> **业务方原话**（2026-10-07）：「……**归到同一个文件夹下做好归类，存放好，避免直接删除**」

⇒ 内容**只会搬进来，不会从这里删掉**。真要淘汰 ⇒ **在这里再标一层「已废弃 + 原因 + 日期」**，⛔ **不是 `rm`**。

### 2.3 每份归档必须带四项（写进 `未进demo/README.md`，此处只记结论）

① **它是什么 / 能跑吗**（⭐ 重点）② **为什么没进 Demo** ③ **怎么用** ④ **日期 + 出处**。

> **理由**：既然这个目录的存在理由是"**让 clone 的人看出可用**"，
> 那么「**可用**」就得**经得起当场验**；没说明的代码 = 跟没归档一样
> （本仓立场：**「用我做过了 ≠ 别人找得到」**）。

⚠️ **三个子目录（`代码/` `文档/` `配置与部署/`）按需创建** —— ⛔ **不预先摆空目录**（本仓立场：**先有内容，再有格子**）。

## 三 · 🔴 探针 = **成功的测试实例 + 配置参考**（⛔ 不是"用完就删"）

> **这是成功的测试实例**，如果需要 demo 的一些配置和设置，**这里面可以参考**。」

⇒ **三条结论**（⛔ 别读成"探针没用了"）：

1. **它是成功的** —— 4 个问题**全部验通**（见 §3.1）。
2. **它被保留** —— 线上那份 Studio **不删**；本地这份目录 **⛔ 不删**。
3. **它是【配置参考实现】** —— 真 demo 要写 Dockerfile / 定端口 / 定头 / 估资源时，
   **先看它**（`Dockerfile` · `app.py` · `requirements.txt` 就是能跑的实物）。

### 3.1 它验的 4 件事 → 各自决定了后面哪件事

| # | 问题 | 实测结论 | 决定了 |
|---|---|---|---|
| 1 | **7860 + Docker 类型**能不能跑 | ✅ 能 | 真 demo **可以走单容器** |

## 五 · 边界（⛔ 别把本 DEC 读成"demo 做完了"）

1. 🔴 **改线 ≠ 交付** —— 本 DEC 只定"**往哪交**"和"**两个目录怎么用**"，
   **真 demo 一行都还没开始做**（顺序仍是 `④` → 乙单 → **`①b` demo 执行方案** → `⑤ 提交 demo`）。
2. 🔴 **`demo/` 不入库 ⇒ 换个会话看不见它** —— 所以 `CLAUDE.md` / `ROADMAP.md` **各留一行指针**；
   ⚠️ **写指针时路径里 ⛔ 不要带 `.md`** —— 它在 gitignore 里，写成 `.md` 路径会被**断链门判红**（实测红过 2 处）。
3. 🔴 **探针【不是】 demo 本体** —— 它只验"平台能不能跑"，**不含业务代码**；
   ⛔ **别把它当成 demo 的起点去改**（真 demo 有自己的 `DEC-098` 设计）。
4. ⚠️ **`DEC-033` 的两条约束仍有效**，见 §一。
5. ⚠️ **本 DEC 是补记** —— 「改动先落地、DEC 后补」这件事本身**违反仓规**（提交前两问①）。
   ⇒ 记在这里，⛔ 别当成可复制的做法。
