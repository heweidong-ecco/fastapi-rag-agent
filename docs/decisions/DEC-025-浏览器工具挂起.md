- 日期：2026-09-21

- 关联：`docs/待办登记-2026-09-20-全仓审计与方向更正.md` **§十三·13.1**（N13）· `README.md`「已知限制 #1」

## 决策事项

`fetch_webpage` / `screenshot_webpage` / `fetch_webpage_html` 依赖 Playwright 的 chromium，
而**本仓任何部署方式都没装它**。**怎么处置？**

## 背景与约束

### 原记录的说法

> 「这三个浏览器工具在本仓的**任何部署方式**下都不可用」—— 只是"能力不可用"，
> 且「`fetch_webpage_html` **压根没注册进 MCP**」。

### 🔴 动手前实测，发现比记录描述的【更糟】

```
mcp_server.TOOLS          = 6 个
LLM 实际看到的工具表        = 同样 6 个（从 TOOLS 派生，2026-09-20 裁「乙」）
实跑 fetch_webpage         → ❌ BrowserType.launch: Executable doesn't exist
                             (.../chromium_headless_shell-1234/...)
```

⇒ **那 2 个工具不只是"不可用"，是【已经在 LLM 手里、每调必炸】。**
LLM 会浪费一轮去调一个注定失败的工具。

### 两条独立的阻塞原因（缺一不可，都实测过）

1. **本仓任何部署方式都没装 chromium** —— `api/Dockerfile` / `docker-compose.yml`
   都没有 `playwright install`（全仓提及它处**全是文档在解释它跑不了**）
2. **本机缓存里的 build 不匹配** —— 缓存是 **1228**（556 MB），而 playwright **1.62 要 1234**

### 约束

- **验证不了就不能装**（业务方口径）：装 chromium 是 **+556 MB**，而本机
  **Docker 镜像构建会打穿 8GB**（记录在案）⇒ **装了也验证不了**。

## 备选方案

| 方案 | 一句话 | 成本 |
|---|---|---|
| 甲 · 装 chromium | `Dockerfile` 加 `playwright install --with-deps chromium` | **+556 MB**（实测，**不是先前估的"约 300MB"**）；⚠️ **本机验证不了构建** |
| **乙 · 摘掉 + 标注**（**采纳**） | 从 `TOOLS` 注释掉 + 4 处一起注释 + 标 `# 可扩展能力` | 0；**能力没了** |
| 丙 · 维持现状 | 什么都改 | 0；但 **LLM 手里始终握着 2 个必炸的工具** |

## 决策与理由

**乙。** 业务方原话：**「只能挂起，用不了，验证不了就不能安装，直接注释掉，在代码中注释写好『# 可扩展能力』」**

1. **验证不了就不装** —— 装了也验不了，等于把一个**未经验证**的东西塞进交付。
2. **不能留"看起来能用"的东西** —— 这是本仓反复在防的形态（`README` 的诚实清单、`§一·B` 的
   「`/docs` 声明与代码相反」都是同一类）。
3. **摘掉顺带修掉一个真缺陷** —— 摘掉后 LLM 工具表 **6 → 4**，**不再握着必失败的工具**。

## 执行内容（**4 处必须一起做，否则会不一致**）

## 🔴 顺带核出：**`ROUTES` 不是可靠的不变量**

改完发现 `len(app.routes)` **没变**（预期 14→12）。实测原因：

```
app.routes 类型分布（改前改后完全一样）:
  Route 4 · _IncludedRouter 3 · APIRoute 5 · Mount 2  = 14
```

⇒ **三个子路由器是以 `_IncludedRouter` 对象整体计入的**（不是把里面的端点摊平）
⇒ **在子路由器里加/删端点，`len(app.routes)` 根本不动。**

⚠️ **本仓一直把 `ROUTES=13/14` 和 `OPENAPI_PATHS=59` 一起当门用** ——
**`ROUTES` 那半边对"子路由器内端点增删"是瞎的**，真正守住的是 `OPENAPI_PATHS`
（本次它 59→57，正确反映了改动）。

📌 **这不是本次引入的问题**，是**一直存在**的判据缺陷。已登记，**未擅自改门**。

## 反悔成本

**低。** 4 处取消注释 + 恢复 2 条用例的 skip 即可。**且代码与注释都留了原位**，
`git log` 也查得到。真正的代价是**能力缺失** —— 但那本来就没有（装了也跑不了）。
