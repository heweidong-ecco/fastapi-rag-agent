## 一 · 要裁的是什么

`api/static/js/sse.test.js` 里那条**结构型守卫**要求：那句拒答语
（`` `api_v1_rag.py` 的 `REFUSAL_SENTENCE` ``）在 `static/js` + `static/web` 里**一个字都不许出现**。

🔴 **它的靶子是【行为】**（前端不许**自己认**拒答 —— 判据只该在后端一处），
**却落地成了关于字节的断言**：`fs.readFileSync(f, 'utf8').includes(REFUSE)` ⇒ **整份文件扫，注释也算**。

**代价（2026-10-06 实测发生）**：我把那句拒答语写进 `chat.html` 的**注释**当例证 ⇒ 守卫当场红
⇒ **我把注释改写掉了**。⇒ **同一块石头还在原地**：下一个写注释解释这条守卫的人，会**再红一次**；
而红了之后最省事的做法**还是**把注释改掉 —— 那就是**每次都要有人白查一遍**。

---

## 二 · 备选

| # | 方案 | 评估 |
|---|---|---|
| **A** | **不动**（维持全文件扫） | ⛔ **成本最低，但它没解决问题** —— 「红了 ⇒ 改注释」这条回路还在，只是被推迟到下次 |
| **B** | **只扫非注释行**（先剥注释再判） | ✅ **改动面最小且直击靶子**；⛔ 代价是"剥"这个动作本身要写对（见 §四） |
| **C** | 换成真正的**词法器 / AST**（用现成解析器） | ⛔ **本仓零 npm 依赖**（`node:test` + `node:assert` 就是全部）⇒ 引解析器 = 给这个仓加打包生态。⚠️ 且**收益不成比例**：要防的是"注释里写了白话"，⛔ 不是"代码里能构造字符串" |
| **D** | **撤掉**这条守卫 | ⛔ **撤掉就等于不再防漂移** —— 前端真自己认起拒答来，**页面上不报任何错**（本仓已栽过同型） |

---

## 三 · 裁定

**取 B。** 并把"剥"这一步**独立成纯函数**（`stripComments`），
使它能被**夹具**测到 —— ⛔ 否则只能拿真仓的文件测，而**真仓的文件不会为了测它而变脏**。

---

## 四 · 有意留的边界（⛔ 别读成遗漏）

1. 🔴 **只剥三种**：HTML 注释 `<!-- -->` · JS 块注释 `/* */` · JS **整行**注释（该行首个非空白即 `//`）。
2. 🔴 **⛔ 有意【不剥】行尾 `//` 注释** —— 剥它要区分 `https://` 里的 `//`，那需要**真词法器**。
   ⚠️ **取舍方向是刻意的**：剥错的方向是**守卫变瞎（假绿）**，比多报一次**糟得多**。
   `N14` 的**实际事故是一整块注释**，本剥法**覆盖得到**。
3. 🔴 **⛔ 剥的是注释，不是字符串** —— 把串拆成 `'无法' + '回答'` 那种**代码**照旧会命中。
   那属于**故意规避**，⛔ **不是本守卫要解决的问题**（本守卫防的是**漂移**）。
   📌 本仓同款既有做法：守卫自己的针脚就是**分两段拼**的（`NEEDLE` / `REFUSE`）——
   ⛔ **那是为了让守卫不绊倒自己，不是让人绕过守卫**。
4. 🔴 **⛔ 同文件里那条孪生守卫（用 `NEEDLE` 的「引用正则只许有一份」）【没有】跟着改**：
   它的针脚是 `来源\s*:` 这种**正则字面量**形状，**解释性文字里不会自然出现**；
   而本条那句是**中文白话**，写注释时**极易**被引到。
   ⇒ **两者风险不同**，⛔ **不顺手一起改**（本仓：**不顺手清理**）。
   ⚠️ 若哪天真在注释里引到了它，**那一次**再按本条的先例单独裁。

## 五 · 判据（可打印）

```bash
node --test api/static/js/sse.test.js
#   ⇒ 34 passed / 0 failed（改前 32）
#   +2 = 本次新增的 `stripComments` 正例 与「代码里要算」反证

# ① 正证：**注释**里含那串 ⇒ 守卫【绿】（这才是 N14 要的）
printf '%s\n' '<!-- 无法回答 当例证 -->' '<p>ok</p>' > api/static/web/__tmp_refuse_probe.html
node --test api/static/js/sse.test.js ; echo "退出码=$?"     # ⇒ 0
rm api/static/web/__tmp_refuse_probe.html

# ② 🔴 反证：**代码**里含那串 ⇒ 守卫【红】且点名
printf '%s\n' 'const x = "无法回答";' > api/static/web/__tmp_refuse_probe.html
node --test api/static/js/sse.test.js ; echo "退出码=$?"     # ⇒ 1，报「前端自己认起拒答来了」
rm api/static/web/__tmp_refuse_probe.html
```

🔴 **② 是本条的命门**：没有它，「剥干净了」与「**把守卫剥瞎了**」在输出上**长得一模一样**。
⇒ 它就是本仓那条**取反检验**的落地：**把结论取反，这条命令的输出要变。**
