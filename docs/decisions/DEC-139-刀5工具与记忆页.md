## 五 · 🔴 顺带照出的两处缺口（**本次才发现**）

### 5.1 规格说「归位」，实际没做：**5 条 Agent 链的【非流式】版一条入口都没有**

规格 §2.1 把 `langgraph_chat` / `advanced_chat` / `plan_execute` / `memory_chat` / `mcp_chat`
的**非流式**版都标着 ⬜ **归位**到「Agent 对话面板（同 `/chat`，换链）」，
而**对话页只接了那 6 条流式链** —— 实测 `app/static/js/sse.js` 的 `CHAINS` 里
**一条非流式路径都没有**（判据：`grep -n "'/api/v1/agent/[a-z_]*'" app/static/js/sse.js` ⇒ 全带 `/stream`）。
⇒ **那 5 条一条可点入口都没有**。

⛔ **不是本页的活**（它们归对话页）⇒ 已登记 **`docs/待办总表.md` 的 `N32`**。

### 5.2 🔴🔴 **`ci-local.sh` 一直是红的，而 CI 是绿的** —— 两道门的**自测夹具不自足**

开刀 5 时跑施工单要求的收尾判据 `bash scripts/ci-local.sh` ⇒ **退出码 1**。
逐层剥出来**两个独立根因**（都与刀 5 的页面**无关**，是**既有缺陷**）：

| # | 根因 | 症状 | 修法 |
|---|---|---|---|
| 1 | **`GIT_DIR` 盖过 `git -C`** —— `ci-local.sh` §3.5 会 `export GIT_DIR=<主检出>/.git`（那是给凭据门用的，`DEC-076`），而这**两道门的自测要造真 git 夹具** | 夹具里的 `git init` **返回 0 却什么都不建** ⇒ 自测**跑到真仓上** ⇒ 反例永远红、正例"绿得没意义" | 自测里 `unset GIT_DIR GIT_WORK_TREE GIT_INDEX_FILE` **+ 一句夹具断言**（`[ -d "${tmp}/.git" ]`） |
| 2 | **夹具漏拷 `ruff.toml`**（**没有** `GIT_DIR` 也成立） | 第 ⑥ 道门（静态检查）在夹具里退到 **ruff 自己的默认规则集**（会带 `I`/`UP`/`EXE`/`RUF100`/`SIM`）⇒ 拷来的 `scripts/*.py` "有新条目" ⇒ 恒红 | 夹具**补拷 `ruff.toml`** |

🔴 **为什么两处都难发现**：**同一份脚本「单独跑绿、`ci-local` 红」**，而**两边测的根本不是同一件事**——
· ①只在 `ci-local` 发生（真 CI 里没有那个 `env`）；
· ②只在 **`PATH` 里有 `venv/bin`** 时发生（`ci-local` 会 `export PATH="${PY_BIN_DIR}:${PATH}"`；单独跑时门**根本找不到 ruff** ⇒ 走"未跑"那一支 ⇒ **绿**）。
⇒ **`ci-local` 报的那句「这个红就是 CI 会红的那个」在这两处【是假的】**（⛔ 不是脚本在撒谎，是这两道门的自测**在别处**会给出假信号）。

⚠️ **两条都做了变异自证**（⛔ 不是"改完看着绿了"）：
· 拿掉 `unset` ⇒ 新加的夹具断言当场 `exit 2` 并打印「**GIT_DIR 被继承了？**」（实测退出码 = **2**，⛔ 不是静默绿）；
· 修正前后跑了三种条件（单独 / `PATH` 带 `venv/bin` / 两者都带）⇒ 8 通过 · 0 失败。

### 🔴🔴 5.2.1 **它不只是"红"，它真的在真仓里提交了一次**（实证）

修之前跑的那次 `ci-local`（18:39:46）**在真仓上落了一个提交**：

```
9dad3c0  init        author: t <t@t>        ← 正是夹具里的 -c user.email=t@t -c user.name=t
        9 files changed, 1377 insertions(+)
```

**逐条对得上**：夹具那句是 `git -C "${FIX}" -c user.email=t@t -c user.name=t commit -qm init` ——
`GIT_DIR` 被继承 ⇒ `-C` 被盖过 ⇒ `init` / `add` / `commit` **三步全打在主检出上**，
把当时**已暂存的工作区**原样提交了。⚠️ **它当时没有推上去**（本地分支），已 `reset --soft` 回退后重提。

📌 **这正是 `scripts/test_check_doc_orphans.sh` 文件头早就写下的那个形态**
（「不摘掉的话，夹具里的 `git add` 会打到**主检出**上（实测：把主检出里未提交的改动 ` M` 悄悄变成已暂存 `M `）」）——
⇒ 本仓**记过**，但**只记在那一份的注释里**，而新加的两道门**没有照做**。
⇒ **「有结构才执行，只有文字就漏」** 的又一例：**同一条教训换个文件就不生效**。

📄 **同族先例** ⇒ `docs/复盘/2026-10-06-守卫的靶子没定准.md`（**门的靶子要定准**）。
