## 最终决策 + 理由

**采纳「甲 · 拆走再删」。理由：**

1. **它同时满足 1 和 2** —— 唯一同时做到"内容不丢"和"污染清干净"的方案。
2. **甲 ↔ 乙 的差别就在那张架构图**：`architecture_full.png` 是**唯一**画了 MCP 层 / 部门制 Agent / 成本控制体系的图，
   把它埋在 `Agent/` 里等于**白留**。搬进 `docs/` 才能被读到。
3. **丙 被业务方的事实推翻**：一个会让人配不出环境、和一个自称"生产级"的文件，**不是加个头标就安全的**。
