# `docs/decisions/` —— 决策记录（DEC）

> 📇 **一份 DEC = 一次【在多个方案之间做过的选择】**，含备选、评估标准、反悔成本。

## 📇 怎么找（⛔ 别列 126 行）

- **文件名自带主题**：`DEC-<序号>-<一句话>.md` ⇒ 直接 `ls | grep <关键词>`
- **顺序 = 时间顺序** ⇒ 不知道编号时，从**大往小**看最近的
- ⚠️ **引用另一份时写 `DEC-nnn`**，别写路径（路径会变）

## 🔴 本层特有的规矩

1. 🔴 **什么时候要写**：**"有没有在多个方案间选过？有 ⇒ 建一份"**。
   **没有 ⇒ 在 commit message 里写明「本次无决策事项」**（⛔ 不答 = 没有这一步）
2. 🔴 **必须含**：备选方案 · 评估标准 · **反悔成本**
3. 🔴 **被推翻时【加取代标记，⛔ 不删、不改写】** —— 例：`DEC-120` 取代 `DEC-119` 的**落点那一半**
4. ⚠️ **DEC 里的旧路径⛔ 不改**（原始记录）—— 断链门对它**整份豁免**
5. ⚠️ **模板** ⇒ `docs/DEC-选型模板.md`
