## 二 · 删的是什么（`F5` · 两个文件）

两个都在 `api/static/` 根下，都是**调试用页**，都**自我引入起就是坏的**：

| 文件 | 大小 | 坏在哪（可打印核过） | 谁在用它 |
|---|---|---|---|
| `stream_test.html` | 218 行 / 9 806 B | 调 **`/api/v1/user/chat_history`** —— 🔴 **该路由全仓不存在** | 无 |
| `trace_viewer.html` | 168 行 / 9 708 B | `fetch` **不带任何认证头** ⇒ 加了鉴权后打开**必 401** | 无（2026-10-06 起已被 `/trace` 取代） |

```bash
# ① 那个接口在仓里【没有】路由定义（命中全是本次新写的注释/说明）
grep -rn 'user/chat_history' api/ --include='*.py'      # ⇒ 只有 main.py / test_web_pages.py 的注释
grep -rn '@[a-z_]*\.\(get\|post\)("/user' api/*.py      # ⇒ 空（整个 /user 前缀一条路由都没有）

# ② 两个页都不带认证头
git show HEAD:api/static/stream_test.html | grep -c 'X-API-Key'   # ⇒ 0
git show HEAD:api/static/trace_viewer.html | grep -c 'X-API-Key'  # ⇒ 0

# ③ 【没有路由直接服务这两个页】—— 它们只经 /static 的 StaticFiles 挂载暴露
grep -rn 'stream_test\|trace_viewer' api/main.py api/api_v1*.py   # ⇒ 只有注释
```

⇒ **三点合起来的结论**：删它俩**不会孤立任何 js / 不会打断任何路由** ——
它们本来就只是「挂在一个静态目录下的、点开要么 404 要么 401 的 HTML」。
删完打旧地址**就是 404**，与它生前的实际效果一致。

## 三 · 为什么删它不算「顺手清理」

本仓有一条纪律：**⛔ 不顺手清理**（`DEC-085` §六·4 原裁「两个存量坏页本刀不碰」）。
`F5` 的**原登记**正是照那条写的 —— ⚠️ 那为什么这次可以删？

> 🔴 **因为"不顺手"指的是【没经授权就动】，⛔ 不是"这类文件永远不许碰"。**
> `F5` 从 `DEC-085` 起就**登记在案**，是**一个待裁的条目**；
> 2026-10-07 业务方**就着这个条目给了话**（§一·1）⇒ **它从"顺手"变成了"派下来的活"。**

⚠️ **别把这条读成"先例作废"**：
- **默认仍是**「先裁再做」—— `F6`/`F7` 这次**都裁了"不动"**（§六），就是"没授权 ⇒ 别动"的正面例子；
- 本份删两个页**有明文的授权来源**（§一·1 那句），⛔ 不是"反正要改这几个文件，顺手一起"。

## 四 · `docs/FAQ.md` 那条**对外指引**怎么处理（⛔ 不留断链）

```text

      概览里「总 Token」「总花费」两格一直是空的（数据不在它读的那条轴上）。
```

⇒ **对外承诺的那条线，指向了一个仍活着的入口**（`/trace` 本来就在，`DEC-093` 建的新页）。

## 六 · `F6` / `F7` 裁「不动」—— 各自是什么意思（⛔ 别读成"做完了"）

### `F6` · `?thread_id=` 空串的**残余 2 条** ⇒ **两条都不加**

`F6` 的**主体**早做过（13 处 `Query("default", min_length=1)` ⇒ 空串挡成 **422**）。
残余是 `ALLOWLIST` 里**两条故意不挡**的：

| 那一条 | 现状 | 为什么不加 `min_length=1` |
|---|---|---|
| `/agent/approve` | 空串 ⇒「**查不到**」（⛔ 不是 500） | 那是**它的语义**，要改就是**另裁一条**（⛔ 不在 `F6` 范围内顺手改） |
| `/agent/token/thread` | **不传 = 所有线程** | 🔴 加了 `min_length=1` ⇒ **改功能**（"不传 = 全部"会变成 422），⛔ 不是补守卫 |

⇒ **裁定「两条都不加」** = **保持现状**。🔴 **这是「裁了不做」，⛔ 不是「做完了」** ——
条目按裁定**关闭**，但**没有任何代码改动**。
📌 现状判据：`venv/bin/python -m pytest api/test_thread_id_guard.py -q`（绿）。

### `F7` · 取消时 token **永远补不上** ⇒ **就这样挂着**

- **事实**（`DEC-084` 实测）：`usage` 只在**最后一帧**回来，而我们提前 `aclose()` ⇒ **那帧到不了**。
- ⚠️ **⛔ 别读成"忘了取"** —— 那是 `DEC-084` **更正过的错误归因**（真因 = **帧到不了**，
  ⛔ 不是 `stream_usage` 没开）。
- 裁定「**就这样挂着**」= **保持现状**：那句「中断未计费」**不是文案选择，是在说事实**。
- ⇒ 将来若要补，**只能另找观测面**（如上游出账），⛔ **不许估算一笔写进账本**（`DEC-084`：**宁可空着，不编数**）。
