### 1.4 剩下 5 条为什么不删、而加 `require_admin`

| 端点 | 为什么不删 | 裁定 |
|---|---|---|
| `GET /debug/count` | **它给的是真事实**（库里到底有多少文档） | ✅ 加 `require_admin` |
| `GET /debug/quota/{user_name}` | 同上（真配额）；⚠️ **收口后仍能查任意用户名** —— **那对管理员是对的**（他就是要能查别人），⛔ **但别把它当"用户自助查询"** | ✅ 加 |
| `GET /debug/cache_stats` | 同上（真读 Redis） | ✅ 加 |
| `GET /debug/rate_limit/{user_name}` | 同上 | ✅ 加 |
| `POST /rag/benchmark-embedding` | 🔴 **它真调 DashScope** ⇒ **删了会少一个"embedding 到底慢在哪"的观测手段**；⚠️ **但它也是唯一一条真烧钱的** ⇒ **必须锁** | ✅ 加 |

🔴🔴 **这一条要单独说清：熔断层与鉴权层是【两件事】**

`/rag/benchmark-embedding` **早就接了 B11 全站日级熔断**（`circuit(global_key())`）。
⚠️ **但熔断管不住它**：

| 层 | 管什么 | 管不住什么 |
|---|---|---|
| **B11 熔断** | 「**全站今天超预算了 ⇒ 谁都别再烧**」 | 「**谁都能烧**」 |
| **`require_admin`** | 「**只有管理员能烧**」 | 「**管理员能烧多少**」 |

⇒ ⛔ **别读成"既然有熔断就不用加鉴权"** —— **两者互补，一条都不能少**。
📌 **本端点收口后的形态**：`require_admin`（**谁能打**）+ `circuit(global_key())`（**还能不能打**）。
⚠️ **它仍然接不上 `B8` 会话级上限** —— 会话级要 `user_name` + `thread_id`，**这里只有身份、没有会话**；
**B11 是全站级、`circuit("global:…")` 不需要用户身份** ⇒ 它仍是唯一能管住这条的那层。

### 2.2 清单归零 ⇒ **守卫必须删掉，⛔ 不能留着一个空清单**

**为什么**：

```python
NON_SPENDING = []           # ← 空

def test_..._stay_unwired():
    for module, func in NON_SPENDING:   # ← 循环体【一次都不执行】
        assert ...                      # ← 断言从不运行
```

⇒ **测试永远绿** ⇒ **它不再钉住任何东西，却还在测试报告里显示"passed"** =
**静默假通过** —— 本仓对这件事有明文纪律（「**空跑 = 静默假通过**」——
⚠️ **它不在本仓里，在我的长期记忆里**，原文记的是"空跑 `pre-commit-gates.py` 是静默假通过"）。

**业务方 2026-10-04 裁**：「**删守卫 + 墓碑进守卫文件**」。

### 3.3 ⚠️ 本份踩的坑：**又一次"注释里也有同样的串"**

我在 `api_v1_rag.py` 的**墓碑注释**里**原样写了** `@router.post("/rag/async_ask", …)`
⇒ `grep -c '@router\.'` **立刻从 12 变成 14**（**墓碑被数成了路由**）。

⇒ **修法**：墓碑里**故意去掉 `@`**，写成 `router.post(...)`，并在注释里写明**为什么**。
⇒ **判据纪律第 2 条**（`CLAUDE.md`）：「**批量替换后按【位置】核，⛔ 别只数"替换了几处"** ——
**注释里也有同样的串**」。
🔴 **这已经是本仓【第三次】栽在同一条上**（`DEC-057` · `DEC-064` · **本份**）——
📌 **同一份 DEC 里，`grep -c 'Depends(require_admin)'` 也踩了同型的一次**：
我在 spec 里写的判据是那条，**实测是 10 不是 6** —— 多出来的 4 处**全在注释/docstring 里**
⇒ 已改成 `grep -c '= Depends(require_admin)'`。

> ⭐ **这条的教训句**：**"数出来一个数"不等于"数对了"** ——
> **每次让 grep 数数之前，先问一句"这个串还会在哪儿出现？"**

## 六 · 反悔成本（**低，但不是零**）

**结论**：**低** —— 4 条删的是**没有真事实的端点**（无消费者）；5 条只是**加了一层依赖**，去掉即恢复。
