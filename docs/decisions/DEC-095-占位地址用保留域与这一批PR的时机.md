## 二 · 为什么是 `example.com`，⛔ 不是 `mail.com`

**⛔ 不靠记忆判断，用 DNS 判**（`dig`，本机 2026-10-07 实测）：

```bash
dig +short MX mail.com        # ⇒ 10 mx01.mail.com.  10 mx00.mail.com.   ← 真有人收信
dig +short MX example.com     # ⇒ 0 .                                    ← null MX（RFC 7505）
dig +short MX example.net     # ⇒ 0 .
```

`example.com` / `example.net` / `example.org` 是 **RFC 2606 保留域**，且挂着 **null MX**（`0 .`）
—— **明确向全网宣告"本域不接收邮件"** ⇒ 寄过去**必然退信，⛔ 不会误投给任何人**。
而 `mail.com` **真有两个 MX 交换器** ⇒ 那是一个**真实运营、可能属于别人**的邮箱。

⇒ 📌 **可复用规则：占位地址一律用保留域**（`example.*` / `.invalid` / `.test`）。
**判据不靠记忆** —— 上面那条 `dig` 就是尺子，且**能把两种情形区分开**。
