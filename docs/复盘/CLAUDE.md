# `docs/复盘/` —— 复盘（**犯过的错**）

> 📇 **一份复盘 = 一个【根因】** —— ⚠️ **根因不同就分记**，⛔ 别塞进同一份。

## 📇 怎么找
- 文件名 = `YYYY-MM-DD-<一句话主题>.md` ⇒ **按日期排序 = 时间线**
- 模板 ⇒ `模板-复盘.md`（就在本目录）

## 🔴 本层特有的规矩
1. 🔴 **写什么**：**"有没有一条该防重犯的？"** ⇒ 有就写
2. 🔴 **一份只能有一个根因** —— 两个根因写两份
3. 🔴 **要能长出【判据】**：复盘末尾给一条**可打印的命令**（⛔ 只写"下次注意"没用）
4. ⚠️ **本目录里的旧路径⛔ 不改**（原始记录）
5. ⚠️ ⛔ **别把复盘当待办清单** —— 它记"发生过什么"，不记"还剩什么没做"
