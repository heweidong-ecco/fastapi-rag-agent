## 二、教训(可复用的判断规则)

> 写成**下次能直接照做的规则**,不写感想。

### ⭐ 规则 1 · **「不存在 / 唯一 / 从来没有」这类全称否定 ⇒ 强制附一条命令**

**判据**：凡是要写 **「X 不存在」「X 是唯一的」「从来没有过」**，
**必须先有一条能打印出来的命令**（`grep -n` / `ls` / `curl`），**把输出贴进结论里**。

**为什么**：
- 全称否定**没法用"我看到过"来证明** —— 只能靠**穷举**。而穷举**必须是一条命令**。
- 本条的 #1 里，"不存在"这个判断**没有任何命令支撑**，它来自**一个空字段**。
- 📌 本仓早就有同族纪律：`ROADMAP.md`「判据」六条的第 2 条 ——
  「**批量替换之后，按【位置】核一遍 —— ⛔ 别只数"替换了几处"**」。
  **这条是它的反面**：别只数"搜到几处 0 命中"——**要打印出搜索范围本身**。

### ⭐ 规则 2 · **响应字段为空 ≠ 该能力不存在** —— 先读 schema，再下结论

**判据**：调接口拿到**空字段 / 空数组 / 空答案**时，**下一步是读请求模型**（`api/schemas.py`），
**不是**推断"端点选错了"。**默认值也是一种"设计"**，它不写在响应里。

**为什么**：`generate_answer` **就是默认 `False`** ——
**"必须显式打开"本身就是这个接口的设计**，而我把它读成了"这个接口做不到"。

### ⭐ 规则 3 · **写进锚点之前，先搜仓里有没有现成说法**

**判据**：要往 **`ROADMAP.md` / `DEC-*` / `施工单`** 这类"会被别人当事实读"的地方写结论前，
**先 `grep` 一遍这个词**（本条的 `generate_answer` / `rag_search` **一搜就能搜到 `docs/demos.md`**）。

**为什么**：**锚点里的错误会被后续每个会话继承** ——
它比代码里的 bug 更贵：bug 会让测试变红，**锚点的错不会**。

### ⭐ 规则 4 · **grep 出 0 命中时，先问「我的模式会不会漏」**（实例 #3 新增）

**判据**：**`grep` 返回空 ≠ 东西不存在** —— 它只说明「**我这条模式**没匹配到」。
写"缺 X"之前，**换一条更宽的模式再搜一次**。

**实例 #3 的具体教训**：

| 我用的模式 | 漏了什么 | 该用的 |
|---|---|---|
| `^[A-Z_]+=` | **注释掉的键**（`# LLM_API_KEY=…`） | `^#?\s*[A-Z_]+=` |

**为什么这类错特别值得防**：它**看起来像"做了检查"** ——
我确实跑了命令、确实拿到了输出，**只是那个输出被错误地解读了**。
⇒ 与规则 1（全称否定要附命令）**配对使用**：**附了命令还不够，还要问"这条命令漏什么"**。

> 📌 **本族在本仓一天内出现 3 次**（#1 空字段 / #2 没查现成文档 / #3 grep 模式漏注释）
> ⇒ **这不是"某一次不小心"，是这套检查方法本身的盲区。**

### ⭐ 规则 5 · **引用一份文档的结论前，回去看那份文档（别凭记忆）**（实例 #4 新增）

**判据**：**"我记得那份 DEC/文档是这么说的" ⇒ 不算证据。**
要写进另一份文档前，**回去打开它、把那句话找出来**。

**实例 #4**：我凭记忆把 `DEC-034` 的「**构建期过滤**」写成了「**`requirements.txt` 已裁掉**」——
**两句话的意思完全不同**（一个改的是**镜像**，一个改的是**仓里的清单**）。
⇒ **一句"我读过那份 DEC"就让这个错穿过了四道门**（写文档 → 自检 → 提交 → 我自己的复核）。

**为什么它比前四条更隐蔽**：前四条是**"没查"**；这条是**"以为查过了"** ——
**后者更难防，因为它带着"我有依据"的感觉。**

> ### 🔴 本族四次的共同结构
>
> ```
> 我手上有一个"看起来像证据"的东西（一个空字段 / 一个 grep 结果 / 一段记忆）
>         ↓
> 我直接从它推出了结论            ← ⛔ 缺的就是这一步：问「它真的支持这个结论吗」
>         ↓
> 写进文档                        ← 而文档会被别人当事实读
> ```
>
> ⭐ **最有效的一条防线：把每个结论写成"可打印的命令"** ——
> 写不出命令的结论（如"我记得 DEC 是这么说的"），**就是还没核过**。
