## 二、教训（可复用的判断规则）

1. ⭐ **判据脚本先自证：拿已知"有"的输入跑一遍。**
   若一次都没见它报过「有」，那它报的「没有」**不构成证据**。
   —— 与 `CLAUDE.md`「把结论写成可打印的命令」配套：**命令本身也要能答"有"**。
2. ⭐ **`cmd | python - <<'PY'` 是坏的写法。** heredoc 重定向的是 stdin，
   管道会被顶掉。要喂管道 ⇒ 用 `python -c`，或**把脚本写成文件**再 `python 文件`。
3. ⭐ **别的工具的输出别猜**：`redis-cli lrange` 出来的是 `json.dumps` 过的串
   （中文是 `\uXXXX`）⇒ 一律**解码后断言**。
4. ⭐ **"两个都报 0"要当成警报**：同一时刻计数涨了、日志有行，
   **而历史 0 条** —— 这三者互相矛盾。**矛盾出现时先怀疑量具**，别急着怀疑被测物。
