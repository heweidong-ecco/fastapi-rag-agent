# 2026-10-09 · 批量替换会制造「语法正确、语义错误」的句子 —— 而 grep 与门都查不出来

> **触发**：`api/` → `app/` 改名（`DEC-126`）过程中，我（Agent）用脚本做全仓路径替换。
> **根因一条**：**替换保证的是"文本变了"，不是"句子还成立"。**
> **严重度**：🟠 中 —— 没有功能损坏（测试全绿），但**留下了两处会骗人的注释**，
> 而它们骗的正是**下一个读代码的人**。

---

## 一 · 发生了什么

改名时我把全仓 `api/...` 替换成 `app/...`。这两处的**原意**是「**反例**」：

### ① `app/agent/agent_graph_advanced.py`

**原文**（示意）：
> server 脚本路径必须**锚在模块自身位置**，不能写 `"api/mcp_server.py"` —— 那是**相对 CWD** 的：
> 本仓起服务的姿势是 `cd api && uvicorn main:app`，从 `api/` 看它解析成 `api/api/mcp_server.py`（**不存在**）

**替换后**：
> ……不能写 `"app/tools/mcp_server.py"`……`cd api && uvicorn main:app`，从 `app/` 看它解析成 `api/app/tools/mcp_server.py`（**不存在**）

🔴 **例子不再成立**：`api/app/...` 这个组合**没有任何人会写出来**，它证不了原来那条结论。

### ② `app/tests/test_agent_repairs.py`

同一段说明的另一个副本（该注释自述是"实测记录"），同样被替换成 `api/app/tools/mcp_server.py`。

**⇒ 两处都已整句重写**（改成 `cd app && …` + `app/app/tools/mcp_server.py`）。

## 四 · 怎么防（**下次做全仓替换时照做**）

1. 🔴 **替换完必须抽读"讲路径的段落"**，⛔ 不能只看 `grep` 有没有命中。
   判据不是"旧串没了"，是"**这段话还成不成立**"。
2. **优先做"能理解句子"的替换**（按真实 rename 映射精确换），⛔ 别用裸目录正则 ——
   本次裸正则还**误伤了 URL**（换行后的 `/api/v1` 被算成 `api/`，抽样里出现 `napi/v1`）。
3. **先 dry-run 抽样打印 before/after**（本次就是靠这一步发现上面那两处的）。
   ⚠️ 但 dry-run **只印了前 12 个文件** —— 那两处在后面，是**事后扫"自伤"**才抓到的
   ⇒ **抽样的量要覆盖到"讲路径的文件"，不是按目录顺序取前 N 个**。
