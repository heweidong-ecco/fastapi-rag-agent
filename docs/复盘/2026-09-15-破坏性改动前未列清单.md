## 二、教训(可复用的判断规则)

1. **批量删除的改动面**在命令里是**不可见**的。`find ... -exec`、`xargs rm`、通配符展开都属于"我写下的是规则,实际发生的是它的求值结果" —— **规则正确 ≠ 求值结果如我所愿**。
2. **钩子拦下 ≠ 我做对了。** 本次是被拦,不是自觉。**把钩子的提示内化成动作**:它说"先跑不带改动的版本",那就每次先跑 —— 而不是等它拦。
3. **未跟踪文件没有 git 兜底。** `archive/`(被 `.gitignore` 忽略)、`.env`、`screenshots/` 等在误删后**无法从仓库恢复**。对这类路径,破坏性操作的门槛应再高一档。
4. **同一动作在不同路径上风险不同。** 删 `__pycache__`(可再生)与删 `archive/`(本地唯一副本)在命令形态上可能只差一个字,但后果不对称 —— **风险判断要看路径性质,不能看命令样子**。
