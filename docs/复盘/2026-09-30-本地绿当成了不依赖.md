# 复盘 · 2026-09-30 · 「**本地绿**」被我当成了「**它不依赖那个东西**」

> 🔴 **一句话**：我给一个新的测试文件写了句 docstring ——「本测试**不需要 Redis、不需要 DB**」。
> **那句是假的。** 它**真的会连库**；本地绿，是因为**本地 Postgres 恰好开着**。
> ⇒ **CI 红了两条**，而 CI 的配置里**根本没有 Postgres**。

---

## 一 · 发生了什么

| 时间 | 事 |
|---|---|
| 2026-09-30 傍晚 | 修 `B9-b`（限流中间件不验签），新增 `api/test_rate_limit_identity.py`（7 条） |
| 本地 | `pytest` 全量 **134 passed / 3 skipped** —— ✅ 全绿 |
| 推送后 | CI（PR #60）**2 failed** ⇒ `psycopg2.OperationalError: connection to server at localhost:5432 failed: Connection refused` |
| 查 | CI 的 workflow 是 `pytest api/ -m "not integration and not needs_db"` —— **只给了 redis service，没有 Postgres** |

**失败的两条**：`test_forged_api_key_does_not_get_its_own_bucket` ·
`test_two_different_forged_keys_land_in_the_same_bucket` ——
它们**没有 stub `auth.verify_api_key`** ⇒ 调到了**真的**验签函数 ⇒ **真去查库** ⇒ 连不上。

---

## 二 · 根因（**不是"忘了加 marker"，是判据错了**）

**我写下的那句话本身就是错的**：

> 「本测试**不需要 Redis、不需要 DB** —— 只断言"怎么从请求头算出一个身份"。
> （理由同 `api/test_public_paths.py`：中间件本体要连 Redis，行为测试会变成环境依赖型通过。）」

**推理链错在哪**：

```
✅ 我确实【没有直接写】DB 调用
❌ ⇒ 但我【推出】了"所以它不碰 DB"
    —— 中间隔着一个我没看的调用：verify_api_key 里就是 with get_db()
```

⇒ **这是"看着像"当"是"**。与我当天早些时候那个脚本 bug
（`for f, sha in {...}.items()` 拆包错、`git show` 静默失败、**我没查返回码**）
**是同一个根因**：

### ⭐ **拿「我观察到的」当「它就是这样」**

## 三 · 为什么本地没抓住

| 为什么 | |
|---|---|
| **本地 Postgres 开着** | 当天早上为了 G6（验证新 Key）**起过 `docker compose up -d`** ⇒ **5432 有人在听** |
| **我跑的是"全量"** | 全量**包含 `needs_db` 的用例** —— 那些在本地**本来就该过**（库在）⇒ **看不出区别** |
| **我没跑 CI 那条命令** | CI 那条是 **`-m "not integration and not needs_db"`** —— **"减掉需要库的"，正是要暴露这个差异** |

> 📌 **判据**：**"本地跑通"证明的是"在这些依赖都具备的机器上它能过"**，
> **⛔ 不证明"它不需要这些依赖"**。
> **要证明后者，必须【把那个依赖拿掉】再跑一次。**

---

## 四 · 怎么修的

1. **让 docstring 说真话** —— 把"不需要 DB"换成**明确的设计约束**，并写明**这次是怎么栽的**。
2. **两条测试补上 `monkeypatch(auth, "verify_api_key", ...)`**。
3. ⭐ **加 `_no_db` autouse fixture**：把 `auth.get_db` 换成**直接抛 `AssertionError`** 的函数
   ⇒ **任何忘写 stub 的用例会立刻报「不许碰数据库」**，
   ⛔ 而不再退化成一个**看起来像环境问题**的 `psycopg2` 报错（**那正是这次误判的形态**）。
4. ⭐ **加自证条** `test_no_db_guard_actually_blocks` ——
   断言那个 fixture **真的拦得住**（否则它只是"我写了"，谁也没验过）。
   **同 `test_public_paths.py` 的 `test_would_have_caught_the_original_bug`。**

### 判据（**可打印** —— 这才是"修好了"）

```bash
# ① 证明不碰库：把 Postgres 指到不可达端口，仍然过
POSTGRES_PORT=1 POSTGRES_HOST=127.0.0.1 python -m pytest api/test_rate_limit_identity.py -q   # → 8 passed

# ② 跑【CI 的同一条命令】，别再拿"全量"代替
python -m pytest api/ -m "not integration and not needs_db" -q                                # → 124 passed, 3 skipped
```

| **1** | ⭐ **"本地绿"不得用来宣称"不依赖某外部服务"** —— 要宣称，**必须把那个服务拿掉再跑一次** | 本文件 · `docs/规范/开发规范.md` |
