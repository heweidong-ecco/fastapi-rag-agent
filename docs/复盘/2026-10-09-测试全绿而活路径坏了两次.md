## 二 · 根因：**测试覆盖的是「行为」，坏掉的是「接线」**

两处都坏在**测试够不到的地方**：

| # | 为什么测试够不到 |
|---|---|
| **1** | **脚本不在 pytest 的采集范围里**（`app/tests/` 之外）。而 CI 的 `compileall` **只查语法** —— 而这是**导入期**错，不是语法错。⇒ **两道防线都不管它。** |

⚠️ **两条用例都没写错。** 错的是**把「全绿」读成「没坏」**。

📌 **这是本仓「拿代理量当判据」的第 N 次**（`2026-10-05-拿代理量当判据.md`）：
「测试通过」是一个**代理量**，它代理的是「**被测到的那些行为**」，
⛔ **不代理「所有接线都通」**。

| **④ 一行 import 上方写清判据** | `app/routing/api_v1_rag.py` 那行 | 「⛔ 别用 `pytest` 当这条的凭证」+ 可打印的真身命令 |

**① 的扫描命令**（可打印，本轮实测找出 4 处活的 + 3 处归档/探针）：

```bash
cd <repo> && ./venv/bin/python - <<'PY'
import re, pathlib
top = {p.stem for p in pathlib.Path("app").glob("*.py")}
groups = {d.name for d in pathlib.Path("app").iterdir() if d.is_dir() and d.name.isidentifier()}
moved = {}
for g in sorted(groups):
    for p in (pathlib.Path("app")/g).glob("*.py"):
        if p.stem != "__init__": moved.setdefault(p.stem, []).append(f"{g}.{p.stem}")
pat = re.compile(r'^\s*from\s+([A-Za-z_]\w*)\s+import\s')
for f in sorted(pathlib.Path(".").rglob("*.py")):
    s = str(f)
    if s.startswith(("venv/", ".git/", "app/", ".claude/worktrees/")): continue
    for i, line in enumerate(f.read_text(encoding="utf-8", errors="ignore").splitlines(), 1):
        m = pat.match(line)
        if m and m.group(1) not in top and m.group(1) not in groups and m.group(1) in moved:
            print(f"{s}:{i}  from {m.group(1)} import …  ⇒ 现在在 {moved[m.group(1)]}")
PY
```
