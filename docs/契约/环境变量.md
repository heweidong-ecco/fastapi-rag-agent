> ## 这份文档是什么
>
> **本项目全部环境变量的权威清单。** 换了机器、新克隆下来、要改配置 —— **只看这一份**。
>
> **权威源**：`api/config.py`（⭐ 集中管理）+ 6 处散落的 `os.getenv`（见 §三，**那是已知的不一致**）。
> **模板**：仓根 `.env.example`（⚠️ **它现在缺 4 个键**，见 §四）。
> **实际值**：仓根 `.env`（**⛔ 不入库**，见 `.gitignore`）。

## 五 · 排查「配置没生效」的顺序

```bash
# ① 先确认键在不在（只看键名，别打印值）
grep -oE '^[A-Z_]+=' .env | tr -d '='

# ② 再确认必填 4 个都非空（validate_config 会替你查，这里只是手查）
for k in DASHSCOPE_API_KEY POSTGRES_PASSWORD JWT_SECRET_KEY LOGIN_PASSWORD; do
  grep -q "^${k}=.." .env && echo "  ✅ ${k}" || echo "  🔴 ${k} 缺失或为空"
done

# ③ 确认 .env 在【仓根】而不是 api/
ls -la .env

# ④ 容器里的话，确认 DOCKER_ENV=true（否则 PG/Redis 会去连 localhost）
docker compose exec api printenv DOCKER_ENV
```

> ⛔ **全程不打印凭据值** —— 只看键名与"是否为空"。
