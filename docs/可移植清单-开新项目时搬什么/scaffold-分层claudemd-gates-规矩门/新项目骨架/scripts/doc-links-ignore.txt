# doc-links-ignore.txt —— 「断链门」的豁免清单
#
# ⚠️ 这是**新项目的空白模板**（从 fastapi-rag-agent 打包过来时，把那份 200 多行的
#    本仓豁免**一条都没带**）——因为那些条目讲的都是**那个仓的历史**，搬过来只会误伤。
#
# ## 什么时候往这里加一条
#
# 断链门（`scripts/check_doc_links.sh`）扫的是【全仓 `.md` 里反引号包起来的路径】。
# 有四种情况它**必然报红，但那不是缺陷**：
#   ① 指向**另一个仓 / 上级目录**（本仓看不到它）
#   ② 指向**已删目录**（历史记录里正常的留痕）
#   ③ **原始记录里的旧路径**（`CHANGELOG` / `docs/复盘/` / `docs/decisions/` —— 那是**留痕**）
#   ④ 同一份名字**在不同时期写过不同简写**
#
# ## 格式（每行一条）
#
#     @file:^docs/decisions/          ← 整个目录豁免（正则匹配【源文件】路径）
#     <一段路径或片段>                 ← 精确豁免那一条
#     以 # 开头                         ← 注释
#
# 🔴 **加一条之前先想清楚「它为什么不算缺陷」** —— 这个文件是给人审阅的，
#    ⛔ 不是"红了就往上丢"的垃圾桶。
#
# ── 下面开始写你自己的 ──
#
# 示例（骨架里就带了这一条 —— 它是真需要的，⛔ 别删）：
#   用户级 CLAUDE.md 在 `~/.claude/` 下，**它不随克隆下来** ⇒ 断链门必然报它。
