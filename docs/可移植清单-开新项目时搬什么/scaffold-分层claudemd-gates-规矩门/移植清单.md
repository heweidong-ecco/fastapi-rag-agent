# 可移植清单 · **开新项目时搬什么**

> ## 这份文档回答什么
>
> 「本仓这套东西里，**哪些是任何项目都能用的**，开新项目时**照抄哪几份、各自要改什么**。」
>
> - **它【不是】本仓的规矩**（本仓的规矩在 `docs/规范/开发规范.md` 与各层 `CLAUDE.md`）
> - **它是一条【单向通道】**：**本仓 → 新项目**。⛔ 反向不成立（新项目的东西别往回搬）
> - 📌 **它是 2026-10-10 实测出来的**，⛔ 不是设计稿 —— 每一格的「要改什么」都跑过命令核过
>
> ## 🔴 什么时候用它
>
> **你要开一个新项目时**（⛔ 平时不用看）。
> ⚠️ **它是触发式的** —— 正因如此，**它没有进 `docs/待办总表.md`**：
> 那里那条硬线是「**`⑤ 提交 demo` 之前未结数必须归零**」，而这一件**只在"要开新项目"时才发生**，
> 挂进去会让那条线**永远差一格**。⇒ **触发条件写在本文开头，就够了。**

## 一 · 先分清三层：**第 3 层⛔ 别搬**

| 层 | 内容 | 与语言 / 框架相关吗 | 结论 |
|---|---|---|---|
| **1 · 骨架** | 分层 `CLAUDE.md` + 它的门 + `settings.json` 的 hooks 注册 | ❌ **完全无关** | ✅ **第一天就有** |
| **2 · 文档治理** | 断链 / 孤儿 / 索引 / 凭据 四道门 + `docs/{decisions,复盘}` + `CHANGELOG` + `待办总表` 的**形态** | ❌ 无关（只依赖 **git + `.md`**） | ✅ **建议第一天就有** |
| **3 · 工程门** | 模块 spec 门 · 路由鉴权门 · ruff 基线门 · 过期导入门 · `spec_status.sh` · `ci-local.sh` | ✅ **强相关**（Python / FastAPI / **本仓的目录约定**） | ⛔ **别搬** |

🔴 **第 3 层为什么不搬**：它守的是**本仓的既成事实**（`app/` 当容器 · 七组 · `sys.path` 根 · FastAPI 路由）。
新项目**长得不一样** ⇒ 搬过去只会得到一堆**恒红或恒绿**的门 —— 而**恒绿的门 = 没有门**（本仓原话）。
⇒ **等新项目长出形状，再各造各的。**

## 二 · 实测清单（**每一格都核过**）

### 2.1 脚本（6 份 · 都在 `scripts/`）

| 文件 | 通用度 | 🔴 搬过去**必须改**什么 |
|---|---|---|
| **`check_layered_claude_md.sh`** | ✅ **几乎不用改** | `PATH_EXEMPT` 里的 `"demo/设置与命令"` 是**本仓专有** ⇒ 删掉。<br>⚠️ `NAME_EXEMPT`（`venv` `venv-ragas` `tmp` `logs` `archive` `screenshots` `self-prompt` `__pycache__` `.mypy_cache` `.pytest_cache` `.ruff_cache` `.mem0` `node_modules`）是**通用约定** ⇒ 保留 |
| **`check_secrets.sh`** | ✅ **通用** | 豁免数据在 `.secret-denylist`（新项目**从空开始**，也可以先不建） |
| **`check_doc_links.sh`** | ✅ **通用** | 豁免数据在 `doc-links-ignore.txt`（同上，从空开始） |
| **`check_ci_job_timeouts.py`** | ✅ **通用** | 默认就读 `.github/workflows/ci.yml` —— 位置本来就是通用的 |
| **`check_doc_orphans.sh`** | 🟡 **半通用** | 🔴 **写死了本仓三个入口名**：<br>`KEY_TARGETS = ["docs/文档地图.md", "ROADMAP.md", "CLAUDE.md"]`<br>⇒ **必须换成新项目的入口名**（新项目若没有"文档地图"这种东西，就把那一项删掉） |
| **`check_index_sync.sh`** | 🟡 **半通用** | 🔴 写死 `INDEX="frontend/索引.md"` + `MIN_ENTRIES=20`<br>⇒ **要么改，要么整份不搬** —— 它是为「**前端有一份索引、且声明了覆盖清单**」这一件事做的，新项目不一定有对应物 |

> 📌 **每份都自带 `--self-test` 或 `test_*.sh`** ⇒ 搬过去**第一件事就是跑它的自测**。
> 本仓立场：**「一条测不出『不成立』的守卫 = 没有守卫」**（`DEC-061`）。

### 2.2 hooks（5 份 · 都在 `.claude/hooks/`）

| 文件 | 通用度 | 说明 |

| **`py-compile-remind.py`** | 🟡 **Python 项目通用** —— 实测 0 处 | 改完 `.py` 当场 `py_compile` 那**一个**文件（⛔ 不是全仓 `compileall`，前者几十毫秒，所以它敢挂在"每次编辑后"） |

### 2.3 文档 / 结构（4 件）

| 搬什么 | 怎么搬 |
|---|---|
| ⭐ **`.claude/settings.json` 的 `hooks` 块** | 🔴 **最容易被漏、漏了就等于没装** —— hooks **放在盘上不会自己跑**，必须在 `settings.json` 里注册。<br>拷过去**删掉用不上的两条**（`spec-remind` / `route-auth-remind`），并把 `statusMessage` 改成新项目真实的门数 |
| **根 `CLAUDE.md` 的骨架** | 搬**形状**：**最高判据 · 判据纪律 · 三个直接入口 · 目录索引**。⛔ **内容全换** |
| **`docs/规范/目录结构与分层CLAUDE规范.md` 的 §六**（**机制那半**） | ✅ **搬**；⛔ §二 / §三 / §四 / §七（`app/` 容器 · 七组 · 导入写法 · 数据文件跟随）**别搬** |
| **`docs/待办总表.md` 的形态** | 搬**形状**：**一份唯一权威** + 别处**只留指针** + 每条**带可打印判据** + 明确的**终结条件** |
| ⬜ **`docs/{decisions,复盘}/` + `CHANGELOG.md` 三件套** | 搬**形状**（一次选择一份 DEC：**备选 / 评估标准 / 反悔成本**；一次犯错一份复盘：**根因 / 判据 / 怎么防重犯**） |

## 三 · 在新项目里怎么落地（**第一天做到这几步**）

1. **`git init -b main`**（⚠️ 分支必须是 `main` —— 本仓的 `ci.yml` 等都以它为准）
2. **建目录 —— 先只有一两个**，⛔ **一开始不用分七组**；**每个目录一份 `CLAUDE.md`**
3. 拷**第 1 层**那几份脚本 + 那 3 个 hook + **注册 `settings.json`**
4. 🔴 **当场验一次**（⛔ 别"装完就算"）：
   ```bash
   bash scripts/check_layered_claude_md.sh              # ⇒ 必须 exit 0
   bash scripts/check_layered_claude_md.sh --self-test  # ⇒ 5 通过 / 0 失败
   bash scripts/check_doc_links.sh                      # ⇒ 0 断链
   bash scripts/check_doc_orphans.sh                    # ⇒ 0 孤儿
   ```
5. **写第一条规矩时同批问一句**：「**它该由哪道门执守？**」
   ⛔ **只写文字 = 下一个「只有文字就漏」** —— 本仓 2026-10-10 补第 ⑧ 道门就是为这件事（`DEC-131`）。

## 四 · 新项目**一开始不该做**的（⛔ 别提前上）

| 别做 | 为什么 |
|---|---|
| ⛔ **照搬七组** | 本仓是**长到 60 个模块**才拆的；新项目体量小的时候分七组是**过度设计**<br>⇒ **「机制从第一天就有；分组等到该分的时候再分」** |
| ⛔ **搬第 3 层那些门** | 它们守的是本仓的既成事实 ⇒ 搬过去不是恒红就是恒绿（见 §一） |
| ⛔ **`@import` 减重** | 官方实测：**导入的文件照样在启动时全量加载**，⛔ 不省上下文。要减重只能用**纯文本指针** |

## 五 · 这份清单**怎么维护**（⛔ 别让它烂掉）

1. 🔴 **本仓那几份被搬的东西改了 ⇒ 同批回来改这里** —— 否则下次开新项目**照着一份过期清单搬**
2. **开过一次新项目 ⇒ 把踩到的坑回写进来**（哪一格"其实还要改"、哪一格"根本不用改"）
   —— ⚠️ **它是实测出来的，也只能靠实测保持准确**
3. ⚠️ **它是【指路】，⛔ 不是复制源** —— **真正被复制的永远是 `scripts/` 与 `.claude/hooks/` 里那些活文件**。
   🔴 **本仓有前科**：一个"启动新项目"的 skill **把路径写死**，而**分层重构挪了目录** ⇒
   它**从那天起就跑不通，而没人知道**（2026-10-10 才发现）。⇒ **⛔ 别把这份清单做成第二个那样的东西。**
