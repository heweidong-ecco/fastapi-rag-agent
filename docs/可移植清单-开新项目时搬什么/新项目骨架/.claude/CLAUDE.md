# `.claude/` —— 本仓的门与 agent 配置

> 📇 **本层 = 本仓挂了哪些自动门、在哪、拦什么。**

## 📇 本目录索引
| 条目 | 是什么 |
|---|---|
| `settings.json` | 项目级配置（**hooks 注册在这里** —— ⚠️ 放盘上不注册 = 没装） |
| `hooks/` | 本仓的 hook 脚本（见 `hooks/CLAUDE.md`） |

## 🔴 本层特有的规矩
- 🔴 **「门挂在别处，就等于没有门」** —— 新加一道门，**必须登记进索引**
- 🔴 **门必须能测出自己会红** —— 没有自测的门 = 装饰
- ⚠️ **hook 只在 Claude 会话里跑**；CI 不触发它们，但**它们的自测要进 CI**
- ⚠️ **提醒型 hook 必须恒 `exit 0`** —— ⛔ 它的失败方式里不许有"把主流程搞挂"
