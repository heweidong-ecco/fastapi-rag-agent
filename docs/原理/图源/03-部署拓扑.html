端口全在回环上 —— 这是有意的安全收窄：
  • 8000 原先是 "8000:8000" = 绑 0.0.0.0 ⇒ 同网段任何人可调这个 API
  • 5432 / 6379 同理；⚠️ Redis 没有口令，暴露面比 Postgres 更大
  • 9090（Prometheus 默认无鉴权）· 3000（Grafana 默认口令）同理
两处仍未解决（⛔ 别读成"全好了"）：
  • Grafana 口令仍是默认值 —— 绑回环只挡住局域网；上公网前必须显式设口令。
  • 看板是【手工配置】的（在 grafana.db 里，仓库无 provisioning） ⇒ 换台机器起来会「容器在、看板没有」。
