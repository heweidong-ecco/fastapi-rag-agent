## 一 · 资产（有什么值得拿）

| # | 资产 | 在哪 |
|---|---|---|
| 1 | **LLM / Embedding 的 API Key**（DashScope · DeepSeek） | `.env`（**不入库**）· 运行时注入 |
| 2 | **钱** —— 每次 LLM 调用都花钱，**没有硬性账单上限**（有全站日级 token 上限） | `app/billing/` |
| 3 | **用户的对话内容 / 上传的文档** | PG（pgvector）· Redis |
| 4 | **登录口令 / JWT 密钥** | `.env` |
| 5 | **API Key 本身** | PG，存 **SHA256 哈希**（⛔ 不存明文） |

## 二 · 信任边界（从哪进）

```
   互联网
     │
     ├─ ① 创空间平台（Demo）—— 单容器 · 平台自己注 Authorization 头
     │      ⚠️ 本仓**不能读**那个头，走 X-API-Key
     │
     └─ ② 本机 / 局域网 —— ⚠️ 2026-10-09 起端口**全绑 127.0.0.1**
            │
   ┌────────┴──────────────────────────────┐
   │  FastAPI（app/）                       │
   │   · 鉴权层（X-API-Key / JWT）           │
   │   · 限流 + 配额（四层）                 │
   │   · Agent / RAG / 工具                  │
   └────────┬──────────────────────────────┘
            │
   ┌────────┴───────┬──────────┬───────────┐
   │ PG             │ Redis    │ 执行器容器 │
   │ 127.0.0.1      │ 无口令    │ 无网络出口 │
   └────────────────┴──────────┴───────────┘
```

## 三 · 攻击者（谁会来）

| 谁 | 想拿什么 | 最可能从哪进 | 现状 |
|---|---|---|---|
| **爬虫 / 脚本小子** | **免费白嫖 LLM**（= 花我的钱） | 直接打公开端点 · 伪造 `X-API-Key` | 🟡 **四层限额挡着**；⚠️ 但**匿名仍绕过用户级配额**（`SECURITY.md` §3.1） |
| **同网段的人** | 同上 | 打 `8000` | ✅ **2026-10-09 已收窄到回环** |
| **看我仓库的人** | 凭据 | 翻 git 历史 | 🟡 **凭据门只扫新增行**；✅ **2026-10-09 加了 gitleaks 扫全历史** |
| **被我执行的代码** | 逃出沙箱 | `execute_python` | ✅ **独立容器**（`read_only` · `cap_drop: ALL` · `no-new-privileges` · 无出网） |
| **平台侧**（创空间） | —— | —— | ⚠️ 它**往每个请求注入 `Authorization` 头**，且 **env 里有阿里云明文凭据** ⇒ ⛔ 别打 `os.environ`、⛔ 别回显请求头 |

| **不做渗透测试** | 个人项目，无预算 |
